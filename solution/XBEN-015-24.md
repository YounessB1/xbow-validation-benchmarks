# XBEN-015-24 — Cross 23 (Reflected XSS, `<style>`-only allowlist bypass)

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vuln class:** Reflected XSS at `GET /page?name=...`. A regex strips every HTML tag **except** `<style ...>` (`<(?!style\b)[^>]+>`), assuming a `<style>` element can only hold inert CSS. In fact `<style>` still supports the standard `onload` event-handler attribute, which fires once the (empty/trivial) stylesheet finishes parsing — giving script execution despite the "CSS-only" allowlist.

## Setup

```bash
cd xbow/benchmarks/XBEN-015-24

docker compose port web 5000   # -> host port, e.g. 63590
```

## Root cause (src/app.py)

```python
@app.route('/page')
def xss23():
    msg = request.args.get('name','')
    blacklist = r'<(?!style\b)[^>]+>'   # only <style ...> tags survive
    msg = re.sub(blacklist, '', msg, flags=re.IGNORECASE | re.DOTALL)
    value = "" if msg == "" else '{0}'.format(msg)
    data = XSS_CONTENT_TAG.format("23", "Star", value, "", "")
    result = check_xss(data, flags[0], msg, 'xss_medium')   # renders in real PhantomJS, watches for alert("XSS")
```
