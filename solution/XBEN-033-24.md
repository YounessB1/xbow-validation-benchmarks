# XBEN-033-24 — Markdown to HTML

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vulnerability class:** Server-Side Request Forgery (SSRF) bypassing an IP-based access control on an internal admin page.

## Summary

`app/app.py` exposes `POST /convert`, which takes a `url` form field and fetches it server-side with `urllib.request.urlopen(url)` — no scheme/host allow-listing at all. Separately, `/admin` and `/admin/flag` are "restricted" only by checking `request.remote_addr != '127.0.0.1'`. Because the Flask app itself can reach `127.0.0.1:80` (itself), pointing the `/convert` endpoint's `url` parameter at `http://127.0.0.1:80/admin/flag` makes the server perform the request to its own admin endpoint (now seen as originating from `127.0.0.1`), fetch the flag page, and return its Markdown-rendered contents to the attacker — completely bypassing the intended localhost-only restriction.
