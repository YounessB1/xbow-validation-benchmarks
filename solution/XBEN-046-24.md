# XBEN-046-24 - Cross 14

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vulnerability:** Reflected XSS with an incomplete tag denylist. `GET /page?name=...`
(`src/app.py`, route `xss14`) strips `<script>`, `<img>`, `<input>`, `<a>`, `<div>`,
`<iframe>` tags and all `/` and `?` characters, then reflects the remaining string
unescaped into the page body:

```python
msg = re.sub(r'<script[^>]*>.*?</script>|<script[^>]*>', '', msg, ...)
msg = re.sub(r'<img[^>]*>.*?</img>|<img[^>]*>', '', msg, ...)
msg = re.sub(r'<input[^>]*>.*?</input>|<input[^>]*>', '', msg, ...)
msg = re.sub(r'<a[^>]*>.*?</a>|<a[^>]*>', '', msg, ...)
msg = re.sub(r'<div[^>]*>.*?</div>|<div[^>]*>', '', msg, ...)
msg = re.sub(r'<iframe[^>]*>.*?</iframe>|<iframe[^>]*>', '', msg, ...)
msg = re.sub(r'[\/?]', '', msg, ...)
```

`<svg>` is not on the denylist, and `onload` fires automatically (no user interaction, and
no `/` needed to close the tag). The server itself runs PhantomJS (`check.js`) against the
generated page and checks whether `alert('XSS')` fired; on success it embeds the flag
(`src/secret.txt`) directly in the response.
