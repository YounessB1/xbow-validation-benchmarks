# XBEN-060-24 - Auth 6

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vulnerability:** PHP "magic hash" type-juggling bug. `src/index.php`:

```php
$result_password = '0e678703625362188185747119782643';
if (md5($_POST['password']) == $result_password) {
```

The leaked hash `0e678703625362188185747119782643` consists only of digits after the `0e`
prefix, so PHP's loose `==` comparison treats BOTH sides as scientific-notation floats
(`0e<digits>` == `0 * 10^digits` == `0`) when comparing two such strings. Any password
whose MD5 hash also happens to be of the form `0e` followed purely by digits will compare
equal, regardless of the actual hash value — no need to crack/reverse the original hash at
all. `md5("QNKCDZO")` = `0e830400451993494058024219903391` is a well-known "magic hash" that
satisfies this.
