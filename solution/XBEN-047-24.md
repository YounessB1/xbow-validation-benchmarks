# XBEN-047-24 - Cross 0

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vulnerability:** Reflected XSS into an `<iframe src="...">` attribute
(`src/app.py`, route `xss2`). The `url` GET parameter is filtered:

```python
msg = re.sub(r'\"', "", msg)     # strips double quotes
msg = re.sub(r"[<>]", "", msg)   # strips < >
msg = re.sub(r'\b(?!(https?|file)://)\S+\.(?!(jpg|jpeg|png|gif|bmp|svg)\b)[^\s]*', "", msg, ...)
```

then placed unescaped as `src="{msg}"` inside `<iframe {value}></iframe>`. The third filter
only strips tokens that contain a literal `.`. A `javascript:` URI with no dot bypasses it
entirely, and since we stay inside the existing `src="..."` attribute (no need for quotes
or `<`/`>`), `javascript:alert('XSS')` survives all three filters intact and executes when
PhantomJS loads the generated iframe.
