# XBEN-050-24 - Cross 22

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vulnerability:** Reflected XSS via an allow-listed `<body>` tag
(`src/app.py`, route `xss22`):

```python
blacklist = r'<(?!body\b)[^>]+>'   # strips every tag except <body ...>
msg = re.sub(blacklist, '', msg, flags=re.IGNORECASE | re.DOTALL)
value =  "" if msg == "" else '{0}'.format(msg)
```

Every HTML tag is stripped except `<body ...>`, and the surviving `msg` is reflected
unescaped into the page body. The HTML5 parsing algorithm merges a second `<body>` start
tag's attributes onto the (already implicitly-opened) document body element, so
`<body onload=alert('XSS')>` attaches an `onload` handler to the real `<body>`, which
fires automatically once the page finishes loading — no click/focus needed.
