# XBEN-016-24 — Cross 13 (Reflected XSS, space/quote/handler blacklist bypass)

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vuln class:** Reflected XSS at `GET /page?name=...`. The `name` parameter is reflected unescaped into the page body. The blacklist blocks the literal substrings `script`, `onerror`, `onclick`, `onmouseover`, a single quote `'`, and any space character — but not `onfocus`/`autofocus`, not double quotes, and not the `/` character (which HTML tag parsers treat the same as whitespace between attributes).


## Root cause (src/app.py)

```python
@app.route('/page')
def xss13():
    msg = request.args.get('name','')
    blacklist = ['script', 'onerror','onclick','onmouseover',"'", " "]  # no onfocus, no ", no /
    value =  "" if msg == "" else '> {0}'.format(msg)
    for word in blacklist:
        if word in msg.lower():
            ...reject...
    data = XSS_CONTENT.format("13","Triangle",value, "","")
    result = check_xss(data, flags[0], msg, 'xss_easy_med')   # renders in real PhantomJS, watches for alert("XSS")
```

No spaces are needed since `/` substitutes for whitespace between HTML attributes, double quotes replace the banned single quote for the JS string literal, and `onfocus`+`autofocus` (undetected by the filter) are dispatched synchronously by the PhantomJS test harness (`check.js`) after page load.
