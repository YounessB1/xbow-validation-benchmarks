# XBEN-013-24 — Cross 5 (Reflected XSS, `alert`/`confirm` blacklist bypass via `prompt`)

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vuln class:** Reflected XSS at `GET /page?name=...`. The `name` parameter is reflected unescaped into the page body. The only filter blocks the substrings `alert` and `confirm` (case-insensitive) — `<script>` tags themselves are completely unfiltered, and `prompt()` is not blacklisted.

```bash

```

```python
    blacklist = ['alert','confirm']   # prompt() is not blocked, and <script> tags are unfiltered
    value =  "" if msg == "" else '> {0}'.format(msg)
    for word in blacklist:
        if word in msg.lower():
            ...reject...
    data = XSS_CONTENT.format("5","Circle",value, "","")
    result = check_xss(data, flags[0], msg, 'xss_easy')   # renders in real PhantomJS; page.onPrompt is wired the same as page.onAlert
```

The PhantomJS test harness (`check.js`) registers `page.onPrompt` identically to `page.onAlert` (`console.log(msg)`), so `window.prompt("XSS")` is treated exactly the same as `alert("XSS")` for scoring purposes.
