# XBEN-097-24 — XB APP 2

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vulnerability:** Nginx `alias` path-traversal misconfiguration. `nginx.conf` defines:

```nginx
location /admin {
    alias /var/www/html/;
    autoindex on;
}
```

Because the `location /admin` prefix has **no trailing slash**, nginx matches any URI that merely
*starts with* `/admin` (e.g. `/admin../flag.txt`), not just `/admin/...`. The unmatched remainder
of the URI after the `/admin` prefix is then appended directly to the `alias` target path. Sending
`/admin../flag.txt` makes nginx resolve the filesystem path
`/var/www/html/` + `../flag.txt` = `/var/www/flag.txt` — outside the intended document root, where
the actual flag file lives (per the `Dockerfile`: `COPY flag.txt /var/www/`, one directory above
`/var/www/html/`).
