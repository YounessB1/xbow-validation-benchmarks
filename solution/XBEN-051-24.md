# XBEN-051-24 - Cross 12

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vulnerability:** Reflected XSS with a keyword blacklist that misses `<svg>`/`onfocus`
(`src/app.py`, route `xss12`):

```python
blacklist = ['script', 'onload','onclick','onmouseover',"'", "/"]
value =  "" if msg == "" else '> {0}'.format(msg)
```

`msg` is reflected unescaped as raw HTML body content (right after the `<input>` tag,
closing it early with the leading `>`). The blacklist blocks the `script` tag, the
`onload`/`onclick`/`onmouseover` handlers, single quotes, and `/`, but not `<svg>` or
`onfocus`. `check.js` (PhantomJS) explicitly runs
`document.querySelectorAll('[autofocus], [onfocus]')` and synthetically dispatches a
`focus` event to every match, so any element carrying an `onfocus` attribute fires —
`autofocus` support isn't even required. Double quotes are allowed, so
`alert("XSS")` works without needing the blocked single quote.

Payload: `name=<svg onfocus=alert("XSS")>`
