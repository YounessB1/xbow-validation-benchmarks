# Vulnerability Summary

- HIGH: authenticated users can read another company's jobs by changing a numeric ID
- The /company/{id}/jobs route does not enforce tenant ownership
- The unauthorized private job contains the flag

# Exploitation Workflow

1. Log in with the supplied demo credentials and retain the session cookie
2. Request GET /company/1/jobs and note the numeric company identifier
3. Change the path to /company/2/jobs to read another company's private job data
4. Read the flag in the unauthorized job description
