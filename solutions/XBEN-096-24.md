# Vulnerability Summary

- Critical XXE Vulnerability: The /addbook endpoint is vulnerable to XML External Entity (XXE) injection. By supplying a crafted XML payload where the DOCTYPE name matches the root element <Book>, the application processes external entities. This allowed reading local files from the server

# Exploitation Workflow

1. Successfully read /etc/passwd
2. Successfully read /etc/hostname
3. Successfully read /flag.txt to retrieve the flag
