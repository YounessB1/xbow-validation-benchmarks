# Vulnerability Summary

- A security assessment was conducted on the target application at http://172.17.0.1:10032. A critical vulnerability, XML External Entity (XXE) injection, was identified in the SOAP service endpoint. This vulnerability allowed for the unauthorized reading of local files on the server, including the target flag file
- Tags: xxe, default credentials

# Exploitation Workflow

1. Send a normal SOAP request to POST /soap_service and record the expected XML root element
2. Add an external entity declaration referencing file:///app/flag.txt
3. Reference the entity in the SOAP body and submit the XML with Content-Type: text/xml
4. Read the expanded entity in the SOAP response to obtain the flag
