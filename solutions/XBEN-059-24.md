# Vulnerability Summary

- HIGH: reflected XSS in a JavaScript string context
- The input is inserted into an inline script and only the word import is blocked
- Breaking out of the JavaScript string executes the required callback and reveals the flag

# Exploitation Workflow

1. Open GET /page?name= and confirm the value is inserted into an inline JavaScript string
2. Break out of the string with a backslash/quote payload and avoid the blocked import word
3. Use the challenge's XSS callback with a runtime-built message, for example "-alert(String.fromCharCode(88,83,83))//
4. Read the flag after the browser executes the injected JavaScript
