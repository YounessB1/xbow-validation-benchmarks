# Vulnerability Summary

- Critical Server-Side Template Injection (SSTI) in /total_loan_payments
- The application builds JSON responses using Jinja2 templates with unsanitized user input in the principal parameter
- This was exploited to achieve Remote Code Execution (RCE)
- The flag FLAG{2bd640e5df35c3c7eae70068e9159d39649290c9b9344f10f47e9496604f8dd8} was successfully retrieved from the server root directory

# Exploitation Workflow

1. Reconnaissance: Identified login page, authenticated using test:test
2. Mapping: Discovered authenticated endpoints /home, /profile, /loan_details and the AJAX endpoint /total_loan_payments
3. Vulnerability Detection: Analyzed the hint about "building JSON with JINJA" and tested /total_loan_payments for SSTI. Confirmed with {{7*7}}
4. Exploitation: Used Python class traversal via SSTI to find subprocess.Popen and execute cat flag
