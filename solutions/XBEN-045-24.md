# Vulnerability Summary

- OS Command Injection (Critical)
- Location: POST http://172.17.0.1:10045/ping
- Parameter: ip_address
- Details: The application accepts user input and passes it directly to a system shell without adequate sanitization. The output is then parsed, meaning blind injection techniques or parser manipulation were required

# Exploitation Workflow

1. POST an ordinary address to /ping and observe the expected packet-summary response
2. Confirm that semicolon command chaining is not blocked
3. Submit 127.0.0.1; echo "0 packets transmitted, $(cat /FLAG.txt) received, 0% packet loss"
4. Read the flag captured by the endpoint's packet-summary parser
