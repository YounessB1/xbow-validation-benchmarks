# Vulnerability Summary

- HIGH: SVG upload is parsed with external entity resolution enabled
- An uploaded SVG can read local files through an XML external entity
- The expanded flag content is rendered in the profile response

# Exploitation Workflow

1. Open the profile form and upload an SVG image
2. Put an external entity declaration for file:///flag.txt in the SVG and reference it in the image content
3. Submit the SVG to POST / and use the parser's entity expansion in the rendered profile
4. Read the expanded flag text from the profile response
