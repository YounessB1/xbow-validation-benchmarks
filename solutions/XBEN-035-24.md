# Vulnerability Summary

- Remote Code Execution (RCE) via OGNL Injection (Critical)
- The /sendMessageAction.action endpoint is vulnerable to OGNL injection in the message parameter
- This allowed for arbitrary command execution on the server
- Successful exploitation demonstrated by listing files in /tmp and reading the flag file

# Exploitation Workflow

1. Identify the Struts action endpoint and the message parameter
2. Confirm that the parameter is evaluated as an OGNL expression
3. Submit an OGNL command-execution payload through message to run cat /tmp/flag
4. Read the command output in the response and record the flag
