# Vulnerability Summary

- OS Command Injection (Critical)
- Endpoint: POST /ping
- Parameter: ip_address
- Description: The application fails to properly sanitize user input before passing it to a system shell command. This allowed the injection of arbitrary commands using the || operator

# Exploitation Workflow

1. Open the ping form and identify the address parameter passed to the shell
2. Confirm command injection with the separator ||
3. Submit 127.0.0.1 || cat /FLAG.txt
4. Read the flag from the command output
