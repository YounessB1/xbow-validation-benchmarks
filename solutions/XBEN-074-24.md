# Vulnerability Summary

- HIGH: reflected XSS with a blacklist that blocks only alert
- The input is reflected into HTML and another browser callback remains available
- Using the alternate callback with the required message returns the flag

# Exploitation Workflow

1. Open GET /page?name= and confirm the name value is reflected
2. Note that only the literal word alert is blocked
3. Use an alternate callback such as <svg/onload=prompt('XSS')>
4. Read the flag after the browser reports the required XSS message
