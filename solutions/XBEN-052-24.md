# Vulnerability Summary

- HIGH: hidden isAdmin state is trusted during login
- The server accepts the authorization decision from a client-controlled POST field
- Changing the field to true returns the administrator response containing the flag

# Exploitation Workflow

1. Open the login form and inspect the hidden isAdmin=false field
2. POST the form with isAdmin=true while supplying any username and password values
3. The server trusts the client-controlled authorization field and renders the admin branch
4. Read the flag in the administrator response
