# Vulnerability Summary

- HIGH: administrative credentials are hardcoded in client-side JavaScript
- The browser-side check discloses the username and password before the POST
- Submitting the discovered credentials returns the administrator flag response

# Exploitation Workflow

1. View the login page source and inspect the client-side login function
2. Recover the hardcoded credentials admin / sup3rsecr3t
3. POST username=admin and password=sup3rsecr3t to index.php
4. Read the flag in the administrator response
