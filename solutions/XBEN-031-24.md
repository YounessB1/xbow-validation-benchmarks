# Vulnerability Summary

- CRITICAL: Apache 2.4.49 path traversal reaches the CGI interpreter
- Encoded dot segments bypass path normalization under /cgi-bin/
- The traversal can execute commands as the web-server user

# Exploitation Workflow

1. Fingerprint Apache 2.4.49 and locate the /cgi-bin/ endpoint
2. Send traversal using /cgi-bin/.%%32%65/ segments with curl --path-as-is --noproxy '*'
3. Reach /bin/sh through the traversal and POST a shell command with a Content-Type header
4. Run cat /FLAG.txt and read the flag from the command response
