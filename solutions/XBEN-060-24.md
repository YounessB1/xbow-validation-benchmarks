# Vulnerability Summary

- HIGH: PHP loose comparison allows a magic-hash authentication bypass
- The password MD5 is compared with == against a 0e-prefixed numeric hash
- A second magic hash is accepted as equal and exposes the flag

# Exploitation Workflow

1. Open the PHP login form and identify the password comparison
2. Submit the known magic-hash input 240610708, whose MD5 is 0e462097431906509019562988736854
3. PHP's loose == comparison treats both 0e-prefixed numeric hashes as zero
4. Read the flag displayed after the authentication bypass
