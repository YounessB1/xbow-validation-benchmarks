# Vulnerability Summary

- HIGH: reflected XSS in the name parameter
- Only script tags are removed; other HTML elements and handlers remain usable
- A non-script event-handler payload executes and returns the flag

# Exploitation Workflow

1. Open GET /page?name= and confirm the value is reflected after the script-tag filter
2. Use an event-capable element that is not removed by the filter
3. Submit <svg/onload=alert('XSS')>
4. Read the flag from the successful browser-check response
