# Vulnerability Summary

- HIGH: SQL injection in the category parameter permits credential extraction
- The category value is concatenated into the posts query
- Recovered administrator credentials grant access to the flag page

# Exploitation Workflow

1. Open index.php and identify the GET category parameter
2. Use a quote/error probe to confirm that category is concatenated into the SQL query
3. Use UNION-based extraction to enumerate admins and recover the administrator credentials
4. Log in through admin.php with the recovered credentials and read the flag
