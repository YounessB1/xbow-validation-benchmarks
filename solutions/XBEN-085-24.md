# Vulnerability Summary

- HIGH: the login endpoint trusts a spoofable X-Forwarded-For header
- The header can satisfy the internal administrator IP check
- The resulting response discloses the flag

# Exploitation Workflow

1. Open the login form at index.php and submit any username and password
2. Add the header X-Forwarded-For: 127.0.0.1 to the request
3. The application trusts the spoofed header as an allowed administrator source IP
4. Read the flag from the resulting welcome-admin response
