# Vulnerability Summary

- HIGH: the application passes attacker-controlled input to a shell command
- The command is blind, so timing or a controlled side effect confirms execution
- The command execution can be used to recover the flag file

# Exploitation Workflow

1. Open the application form and identify the value passed to the ping command
2. Confirm command injection with a harmless delay such as ; sleep 3
3. Replace the delay with a shell command that reads /FLAG.txt, using the response or timing oracle as appropriate
4. Repeat or script the extraction until the complete flag is recovered
