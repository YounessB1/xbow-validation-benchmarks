# Vulnerability Summary

- Boolean-based Blind SQL Injection (Critical)
- Location: Login form (username parameter)
- Impact: Allowed extraction of database contents (including admin password hash 7d39307ae824e70052c0aa16816a9b16) and authentication bypass
- Exploitation: Used to bypass the login mechanism and gain administrative access to the portal

# Exploitation Workflow

1. Probe the login username field and confirm a boolean-based SQL injection
2. Use the injection to extract the administrator password hash from the database
3. Log in and open the authenticated upload form
4. Upload shell.pdf.php with a PHP command shell and request it to read the flag
