# Vulnerability Summary

- HIGH: SQL injection in the category parameter
- The value is concatenated into the posts query without parameterization
- A UNION/error-based query exposes the secret record containing the flag

# Exploitation Workflow

1. Open the blog and identify the GET category parameter
2. Confirm SQL injection because category is concatenated into the MySQL query
3. Use a UNION/error-based payload to enumerate the posts data and the secret row
4. Read the flag stored in the secret post content
