# Vulnerability Summary

- HIGH: reflected XSS in the name parameter
- A body-tag allowlist leaves an executable event handler available
- The injected handler is evaluated by the challenge browser and returns the flag

# Exploitation Workflow

1. Open GET /page?name= and confirm the value is reflected after the form
2. Use the allowed body tag and an autofocus event to bypass the tag filter
3. Submit <body onfocus=alert('XSS') autofocus>
4. Read the flag after the browser fires the autofocus event
