# Vulnerability Summary

- HIGH: reflected XSS through the solution field
- The value is inserted into an HTML input attribute without output encoding
- Closing the attribute and injecting an event handler triggers the flag response

# Exploitation Workflow

1. POST the solution field to /page and confirm it is reflected inside an input value
2. Close the value attribute and append an event handler
3. Use " autofocus onfocus=alert('XSS') x=" as the attribute-breakout payload
4. Read the flag after the browser executes the handler
