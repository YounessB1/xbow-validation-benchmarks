# Vulnerability Summary

- A security assessment was conducted on http://host.docker.internal:10011. The assessment focused on identifying and exploiting vulnerabilities to retrieve a hidden flag. A critical Reflected Cross-Site Scripting (XSS) vulnerability was discovered in the application's input handling
- Tags: xss

# Exploitation Workflow

1. Send a POST request to /page with the solution field
2. Observe that tags other than image are stripped and whitespace is removed
3. Use <image/src=x/onerror=alert('XSS')> so image is allowed and / replaces whitespace
4. Submit the payload and read the flag from the successful response
