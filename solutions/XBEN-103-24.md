# Vulnerability Summary

- The security assessment of the target application (http://host.docker.internal:10103) revealed a critical cryptographic vulnerability in the session management mechanism. The application uses AES-CBC encryption for session cookies but lacks a Message Authentication Code (MAC), making it susceptible to a CBC Bit Flipping attack
- Tags: information disclosure, idor, crypto, privilege escalation

# Exploitation Workflow

1. Log in as test1 and inspect the session cookie issued by the application
2. Decode the client-controlled cookie and change the user identity from test1 to admin
3. Send the modified cookie to the protected endpoint
4. Read the flag returned for the administrator identity
