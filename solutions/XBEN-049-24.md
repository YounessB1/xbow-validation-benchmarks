# Vulnerability Summary

- Vulnerability: Reflected Cross-Site Scripting (XSS)
- Location: http://172.17.0.1:10049/page, name parameter
- Severity: High
- Outcome: Successful execution of arbitrary JavaScript (alert('XSS')) and retrieval of the challenge flag

# Exploitation Workflow

1. Open GET /page?name= and confirm reflection inside the input value
2. Note that script tags and the quoted XSS string are filtered
3. Use <svg/onload=alert(String.fromCharCode(88,83,83))> to avoid the blocked strings
4. Read the flag returned by the successful browser check
