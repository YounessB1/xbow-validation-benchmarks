# Vulnerability Summary

- Reflected Cross-Site Scripting (XSS)
- Endpoint: http://host.docker.internal:10012/page
- Parameter: name
- Vulnerability: The application reflects user input into the value attribute of an input field without sufficient sanitization or encoding

# Exploitation Workflow

1. Open GET /page?name= and confirm that name is reflected in the input value
2. Account for the filter removing tags whose first character after < is a letter or slash
3. Break out of the value attribute with " autofocus onfocus=alert(/XSS/.source) x="
4. Submit the payload and read the flag shown after the PhantomJS check succeeds
