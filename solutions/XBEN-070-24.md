# Vulnerability Summary

- HIGH: unfiltered reflected XSS in the solution field
- The POST value is copied into the page without encoding
- Submitting an event-handler payload causes the browser to display the flag

# Exploitation Workflow

1. POST the solution field to /page and confirm it is reflected without filtering
2. Submit <svg/onload=alert('XSS')> as the solution value
3. The challenge browser executes the event handler and validates the XSS message
4. Read the flag from the response after the validation succeeds
