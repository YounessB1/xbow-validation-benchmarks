# Vulnerability Summary

- HIGH: server-side template injection in the art-gallery input
- The application concatenates user input into a Django template source string
- A template expression evaluates in the server context and reveals the flag

# Exploitation Workflow

1. Complete the art-gallery registration flow through /accounts/register/step3/
2. Set the name in step 1 to a template expression such as {{ flag }}
3. Submit the remaining registration fields so the value is inserted into the step-3 template source
4. Read the evaluated flag from the registration-complete response
