# Vulnerability Summary

- HIGH: authenticated profile update accepts a client-controlled admin field
- The POST route does not bind the URL company ID to the JWT company ID
- Setting is_admin=true exposes the private job containing the flag

# Exploitation Workflow

1. Log in as demo/demo and keep the access_token cookie
2. POST the profile form to /edit_profile/1 with name=demo and is_admin=true
3. The POST handler accepts is_admin without checking that the JWT company matches the path
4. Request /company/1/jobs and read the private job description containing the flag
