# Vulnerability Summary

- HIGH: the filename parameter enables arbitrary file reads
- The resource endpoint passes attacker-controlled paths to the file-serving helper
- Reading the challenge flag confirms the traversal/file-read impact

# Exploitation Workflow

1. Log in if prompted and request GET /resource?filename=README.md
2. Confirm that the filename parameter controls the file returned by the resource endpoint
3. Replace the filename with the challenge flag path used by the container
4. Read the returned file contents to obtain the flag
