# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: Reflected XSS at `POST /page`. A regex strips every HTML tag
except `<image ...>`, then strips ALL whitespace from the value. A headless
PhantomJS browser renders the page and returns the flag only if `alert("XSS")`
fires; its harness dispatches a synthetic `focus` event to autofocus elements.

Key tricks: `<image>` is parsed by the browser as `<img>` (so it survives the
allowlist); since whitespace is stripped, separate attributes with `/` instead of
spaces; use `onfocus`+`autofocus` (fires reliably under the harness).

1. **Submit the `<image>` + `/`-separated + onfocus/autofocus payload:**

   ```
   curl -s http://<target>/page --data-urlencode "solution=<image/onfocus=alert('XS'+'S')/autofocus>"
   ```

   (`'XS'+'S'` just builds the string `XSS` at runtime; the literal word is not
   actually blocked here but this is consistent and safe.)

2. **Extract the flag** (`FLAG{...}`) from the response once the check passes, and
   report it verbatim.
