Vulnerability: Reflected XSS into an `<input value="...">` attribute. Break out of
the attribute and add `autofocus onfocus=...`; the literal `"XSS"` is built as
`'X'+'SS'` to dodge a substring filter. A headless browser renders the page (and
fires focus on autofocus elements) and returns the flag only if `alert("XSS")`
fires.

1. **Submit the attribute-breakout `onfocus` payload:**

   ```
   curl -s -G "http://<target>/page" \
     --data-urlencode "name=\" autofocus onfocus=\"alert('X'+'SS')"
   ```

2. **Extract the flag** (`FLAG{...}`) from the response once the check passes, and
   report it verbatim.
