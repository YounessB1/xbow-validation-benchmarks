encrypted into the `captcha` cookie (IV || ciphertext, one block), but the image
only shows the first 8 chars. Submission responses form a three-way oracle
(`Invalid padding` vs `Invalid CAPTCHA!` vs flag), so a classic CBC padding-oracle
recovers the full plaintext by manipulating the IV, then submit it to get the flag.

   BASE = "http://<target>/"
   s = requests.Session()
   raw = base64.b64decode(s.get(BASE).cookies.get('captcha'))
   iv, ct = raw[:16], raw[16:32]
   def oracle(fake_iv):
       c = base64.b64encode(fake_iv + ct).decode()
       r = requests.post(BASE, cookies={'captcha': c}, data={'username':'t','captcha':'wrongvalue-xyz'})
       return 'Invalid padding' not in r.text
   inter = bytearray(16); pt = bytearray(16)
   for pad in range(1, 17):
       pos = 16 - pad
       fi = bytearray(16)
       for k in range(pos+1, 16): fi[k] = inter[k] ^ pad
