# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: Reflected XSS at `GET /page?name=...`. The `name` value is
reflected unescaped into the body. The only filter blocks the substrings `alert`
and `confirm` — `<script>` is unfiltered and `prompt()` is not blocked. The
headless PhantomJS harness treats `window.prompt("XSS")` the same as
`alert("XSS")` for scoring.

1. **Submit a `<script>` that calls `prompt('XSS')`** (avoid `alert`/`confirm`):

   ```
   curl -s -G http://<target>/page --data-urlencode "name=<script>prompt('XSS')</script>"
   ```

2. **Extract the flag** (`FLAG{...}`) from the response once the check passes, and
   report it verbatim.
