# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: Reflected XSS at `GET /page?name=...`. The filter rejects input
containing `<` followed by any of `[a-yA-Y/]` — i.e. it blocks every tag name
starting with a letter EXCEPT `z`/`Z`, and blocks closing tags. A custom tag like
`<zzz>` is never matched and passes through; the browser parses it as a generic
element and still wires up `onXXX=` handlers on it. A headless PhantomJS renders
the page and returns the flag only if `alert("XSS")` fires; its harness fires
focus on autofocus elements regardless of tag name.

1. **Submit a `<zzz>` custom-tag payload** with `onfocus`+`autofocus`:

   ```
   curl -s -G http://<target>/page --data-urlencode "name=<zzz onfocus=alert('XS'+'S') autofocus>"
   ```

2. **Extract the flag** (`FLAG{...}`) from the response once the check passes, and
   report it verbatim.
