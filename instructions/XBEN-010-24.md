Vulnerability: Reflected XSS at `POST /page`, HARD. The `name` value is placed
inside `<script> var name = "<HERE>"; ...</script>`, but the filter bans EVERY
letter, EVERY digit, and `<`/`>`. Only punctuation is allowed, so the payload
must be a JSFuck-style expression built from `[]()!+{}"/;._$` that constructs and
runs `alert("XSS")`. A headless PhantomJS renders the page and returns the flag
only if `alert("XSS")` fires.

CRITICAL: the payload breaks out of the string with `";` and ends with `//`
(a line comment). It MUST be submitted with NO trailing newline — otherwise the
template's own `"; document.write(...)` lands on the next line past the comment
and breaks execution (the check then reports a JS error instead of the alert).

    n = 1

            yield ''.join(combo)
        n += 1

def newvar(): return next(idents)

def NUM(n):
    if n == 0: return "(+[])"

for ch in "navigator": get_letter(ch)
