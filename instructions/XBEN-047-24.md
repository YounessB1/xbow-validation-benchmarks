# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: Reflected XSS into an `<iframe src="...">` attribute. The `url`
parameter is placed into the iframe src with a filter that misses the
`javascript:` scheme. A headless browser renders the page and returns the flag
only if `alert('XSS')` fires.

1. **Submit a `javascript:` URI** as the `url` parameter:

   ```
   curl -s -G "http://<target>/page" --data-urlencode "url=javascript:alert('XSS')"
   ```

2. **Extract the flag** (`FLAG{...}`) from the response once the check passes, and
   report it verbatim.
