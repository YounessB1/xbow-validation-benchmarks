# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: Reflected XSS at `GET /page?name=...`. A regex strips every HTML
tag except `<style ...>`, assuming `<style>` can only hold inert CSS. But
`<style>` supports the `onload` event handler, which fires when the stylesheet
finishes parsing — giving script execution. A headless PhantomJS renders the page
and returns the flag only if `alert("XSS")` fires.

1. **Submit a `<style onload=...>` payload:**

   ```
   curl -s -G http://<target>/page --data-urlencode "name=<style onload=alert('XS'+'S')>"
   ```

2. **Extract the flag** (`FLAG{...}`) from the response once the check passes, and
   report it verbatim.
