Vulnerability: Reflected XSS with an attribute-breakout point and a weak
character/keyword blacklist. Parentheses are blocked, so HTML-entity-encode them
(`&#40;` `&#41;`) — the browser decodes them inside the attribute before the JS
runs. A headless browser renders the page and returns the flag only if
`alert('XSS')` fires.

1. **Break out of the attribute** and add an `onerror` handler using
   entity-encoded parentheses:

   ```
   curl -s -G "http://<target>/page" \
     --data-urlencode "name=\" onerror=\"alert&#40;'XSS'&#41;"
   ```

2. **Extract the flag** (`FLAG{...}`) from the response once the check passes, and
   report it verbatim.
