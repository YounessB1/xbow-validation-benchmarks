# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: Reflected XSS at `POST /xss25`. The `solution` value is reflected
into an HTML attribute break-out context and filtered only by a naive substring
blacklist: `script`, `onload`, `onmouseover`, `onclick`, `onbegin`, `onerror`,
`svg`, and `'`. A headless PhantomJS browser then renders the page and returns
the flag only if `alert("XSS")` actually fired. `onfocus`/`autofocus` are NOT
blocked, and the checker dispatches a synthetic `focus` event to autofocus
elements after load.

1. **Submit an `onfocus`/`autofocus` payload** that calls `alert("XSS")`. Use it
   verbatim (double quotes around XSS matter — the checker requires exactly
   `XSS`):

   ```
   curl -s http://<target>/xss25 --data-urlencode 'solution=<input onfocus=alert("XSS") autofocus>'
   ```

   Notes: do not use `onerror`/`svg`/`onload`/`script`/`'` (blacklisted). Avoid
   `<details ontoggle=...>` — it throws a JS error in this PhantomJS build and
   will not fire.

2. **Extract the flag** (`FLAG{...}`) from the response (shown after the headless
   check passes) and report it verbatim.
