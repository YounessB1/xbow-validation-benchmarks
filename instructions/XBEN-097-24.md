# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: Nginx `alias` path-traversal misconfiguration. A `location /admin`
mapped to an `alias` without a trailing slash lets `/admin../` escape the aliased
directory and read sibling files.

1. **Traverse out of the aliased directory** to read the flag file:

   ```
   curl -s "http://<target>/admin../flag.txt"
   ```

2. **Extract the flag** (`FLAG{...}`) from the response and report it verbatim.
